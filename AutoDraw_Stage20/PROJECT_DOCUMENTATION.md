## 1.3. Основные точки входа и сборка

Проверены файлы верхнего уровня `AutoDraw_Stage20/`:

| Файл | Назначение по содержимому |
|---|---|
| `integrated_app.py` | Основное объединённое GUI-приложение; размер на HEAD — 39 982 байта |
| `launcher.py` | Совместимая точка запуска, импортирующая `main` из `integrated_app` |
| `run_source.bat` | Windows-запуск исходного приложения |
| `build_windows.bat` | Windows-обёртка установки зависимостей, тестов, сборки и smoke-test |
| `build_windows.py` | Сборка portable-приложения через PyInstaller |
| `smoke_test_portable.py` | Проверка собранного приложения |
| `run_all_tests.py`, `run_tests.bat` | Запуск тестов |
| `app_features.json` | Манифест поддерживаемых функций для build metadata |

В `launcher.py` нет отдельной логики приложения: он импортирует `integrated_app.main` и завершает процесс кодом возврата этой функции.

Сборочный сценарий `build_windows.bat` рассчитан на Windows и Python 3.11 x64 с Tcl/Tk. Он создаёт отдельное окружение `.venv-build`, устанавливает build/runtime зависимости, запускает тесты, сборку и smoke-test. `build_windows.py` использует PyInstaller в режиме `onedir` и формирует portable-каталог. Детальная проверка корректности сборочной логики относится к последующим этапам.

- [Run #770 — 41127256212](https://github.com/Kiddos19882/AutoDraw/actions/runs/41127256212), SHA `445014b5e2c13e9d1eb8a78177d2400aee0d2515`;

- `geometry-tests` — `in_progress` на момент проверки; выполнялся benchmark Stage 8;
- `Windows portable build and startup smoke-test` — `completed / failure`.

В логе Windows job обнаружена конкретная причина падения: Python не может импортировать `brush_behavior_test_ui.py`, поскольку на строке 141 находится синтаксически некорректный фрагмент `},,`. Ошибка возникает при импорте `BrushBehaviorTestTab` из `integrated_app.py` и приводит к `SyntaxError: invalid syntax`. Текущий файл действительно содержит двойную запятую после записи сценария «Замкнутый контур одной траекторией».

Это подтверждённый дефект текущего HEAD, а не предположение по одному только статусу CI. Исправление **не выполнялось**, поскольку текущая работа ограничена анализом. Необходимо устранить дефект отдельным поручением либо после согласования исправлений; до этого успешный запуск приложения и Windows portable build не подтверждены.
