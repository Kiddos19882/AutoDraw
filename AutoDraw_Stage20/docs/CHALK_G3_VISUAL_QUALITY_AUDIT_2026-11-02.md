## 2. Визуальные результаты

Во всех шести снимках:
- все шесть штрихов визуально непрерывные;
- заметных разрывов, пропущенных сегментов или отдельных точек вместо линии не обнаружено;
- горизонтальность и прямолинейность визуально сохранены;
- ширина штрихов выглядит стабильной вдоль каждой линии и между повторами;
- межлинейный шаг выглядит равномерным;
- края штрихов округлые, без заметного резкого обрыва;
- явных артефактов от sampling step=4 на этой геометрии не видно.

Сравнение delay=5 и delay=10 не выявило видимого различия в непрерывности, толщине, длине или гладкости линий. Результаты шести captures визуально согласованы.

**Ограничение снимка:** курсор кисти находится у правого конца шестой линии и частично перекрывает её окончание во всех captures. Поэтому точная форма конечного cap шестой линии не подтверждена по этим PNG. Остальные окончания видны.

Это ручная визуальная оценка сохранённых raster captures. Она не является полноценным автоматическим pixel segmentation отчётом: точные метрики максимального gap, centerline deviation и распределения ширины не рассчитывались. Нельзя приписывать этим снимкам точность измерения в долях пикселя.

## 3. Сопоставление с CHALK и исполнением

| Метрика | step=4 / delay=5 | step=4 / delay=10 |
|---|---:|---:|
| CHALK по повторам | 366 / 366 / 365 | 363 / 366 / 366 |
| Средний CHALK | 365.67 | 365.00 |
| Move calls на запуск | 768 | 768 |
| Длительность | 17.984 / 17.984 / 18.016 s | 18.000 / 18.031 / 18.079 s |
| Визуально непрерывных линий | 6/6 во всех повторах | 6/6 во всех повторах |

Разница среднего расхода между профилями составляет около 0.67 CHALK на шесть линий (около 0.18%), что меньше разброса между отдельными повторами. В измеренной серии практически эквивалентны и расход, и время.

Game Monitor exact CHALK остаётся источником точного расхода. ROI `changed_pixels_in_roi` в experiment metadata не является самостоятельной метрикой непрерывности: прямоугольник ROI может включать cursor/прочие изменения. Эти значения не использовались для объявления отсутствия разрывов; вывод о видимой непрерывности основан на непосредственном просмотре шести PNG.

## 4. Решение

1. Для сценария `paint_consumption_long_lines` с шестью длинными горизонтальными линиями, radius=10, step=4 оба профиля delay=5 и delay=10 прошли визуальную проверку по сохранённым снимкам.
2. По измеренным CHALK и времени профили практически равнозначны. Оснований считать delay=5 заметно более экономичным или быстрым нет.
3. Для этого узкого сценария можно использовать step=4 как подтверждённый экспериментальный режим с хорошим визуальным результатом.
4. Не назначать step=4 универсальным default для AutoDraw: ещё не проверены диагонали, короткие штрихи, кривые, углы, замыкания, пересечения, близкие параллельные линии и заливки.
5. Не менять production executor defaults до независимой validation на реальных изображениях и проверок остальных геометрий.
