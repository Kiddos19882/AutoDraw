## Получение сборки

1. Открой страницу workflow [41513389663](https://github.com/Kiddos19882/AutoDraw/actions/runs/41513389663).
2. В разделе Artifacts скачай `autodraw-g3-preflight-build`.
3. Распакуй в отдельную новую папку. Не смешивай с предыдущими сборками и не заменяй рабочую версию AutoDraw.
4. Запусти portable-приложение. Сборка создана из ветки `feature/image-geometry-optimization`, code commit `ca8c9b3bd739ea0a5b557b87fc0106ecfde81216`.

## Проверки без рисования

1. Открой игру в браузере обычным способом и перейди к тестовой доске.
2. Убедись, что доска видна целиком и не перекрыта окнами; масштаб браузера и Windows display scaling не менялись относительно калибровки.
3. Запусти AutoDraw и открой Brush Test.
4. Проверь, что профиль калибровки загружен, область доски/координаты распознаны, каталог результатов доступен для записи.
5. Проверь Game Monitor/Bridge: свежий heartbeat, обнаруженная игровая доска и доступный точный CHALK pointCount. Если heartbeat устарел, доска не найдена или CHALK не exact — остановись.
6. Проверь эталон пустой доски. Нужны чистая доска и достоверный baseline pointCount.
7. Целевой радиус — 10. Если выполняешь автоматическую установку кисти, используй штатный drag-механизм и дождись подтверждения Game Monitor: фактический radius ровно `[10]`, статус `single`.

## Ограничения

- Не нажимай запуск полного блока INT006.
- Не запускай D1–D5 вручную и не используй старые V1–V5 journals для новой серии.
- Не выполняй 45 captures до проверки результатов preflight.
- Не меняй production estimator, sampling defaults или параметры модели.

На preflight проверяются запуск приложения, калибровка, heartbeat, точный CHALK snapshot и состояние доски. Если пункт требует реального рисования, остановись и сообщи об этом.

## Что сообщить после проверки

Сообщи, запустилось ли приложение; загружен ли профиль калибровки; видит ли Game Monitor доску и свежий heartbeat; показывает ли exact CHALK pointCount; подтверждена ли чистая доска; подтверждён ли radius 10 (если выполнялась установка). При ошибке приложи скриншот AutoDraw и Game Monitor. Не отправляй cookies, пароли или игровые токены.
