# История изменений документации и проекта

Файл предназначен для значимых изменений, заметных разработчику или пользователю. Технические подробности отдельных задач остаются в WORK_LOG и соответствующих тематических документах.

## Unreleased

### Documentation
- Добавлен единый каталог структурной документации в `docs/`.
- Добавлены документы архитектуры, каталога компонентов, конфигурации и данных, разработки и сборки.
- Добавлены файлы управления проектом: статус, план, реестр задач, журнал решений и журнал работ.

## Правила ведения

- Не добавлять сюда каждое мелкое исправление опечатки.
- Группировать изменения по версиям или датам.
- Не заявлять о функциях, которых нет в текущей версии исходников.
- Не переносить сюда аналитические выводы о поведении программы.
- Ссылаться на commit, если изменение уже зафиксировано в Git.
