# Журнал проектных решений

Этот файл фиксирует организационные и документационные решения. Решения о внутренних алгоритмах здесь не рассматриваются.

## DEC-001. Основная точка входа в документацию

**Статус:** принято  
**Решение:** каталог `AutoDraw_Stage20/docs/` используется как единый индекс структурной документации и управления проектом.  
**Причина:** разделить справочные материалы, планы и журналы, не перегружая README приложения.  
**Последствие:** новые общие документы добавляются через `docs/README.md`.

## DEC-002. Исторические документы сохраняются

**Статус:** принято  
**Решение:** ранее созданные Markdown-файлы в корне Stage20 не удаляются в рамках создания нового комплекта.  
**Причина:** они содержат историю работ и специализированные сведения.  
**Последствие:** новый индекс ссылается на них, но не копирует целиком их содержимое.

## DEC-003. Документация отделена от анализа поведения

**Статус:** принято  
**Решение:** структурная документация описывает расположение, назначение, точки входа, конфигурацию и способы работы с репозиторием.  
**Не входит:** оценка корректности алгоритмов, производительности, качества рисунка, точности измерений и поведения программы.  
**Последствие:** подобные выводы не добавляются в новые документы.

## DEC-004. Исходный код не изменяется в документационной инициативе

**Статус:** принято  
**Решение:** в рамках текущей задачи разрешены только Markdown-изменения.  
**Последствие:** найденные расхождения фиксируются как вопросы документации, а не исправляются в коде.

## DEC-005. Рабочая ветка

**Статус:** принято  
**Решение:** документационные изменения выполняются в `feature/image-geometry-optimization`.  
**Ограничение:** `master` не изменяется в рамках текущей задачи.
