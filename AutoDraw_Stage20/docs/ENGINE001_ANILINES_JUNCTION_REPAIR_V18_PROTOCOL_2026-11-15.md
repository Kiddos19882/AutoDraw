## Experimental variants and fixed parameters

**Shared source and masks:** same V14 output, threshold128, same `skimage.skeletonize` (no closing, dilation, learned stage, adaptive color or noise pruning). Treat source pixel as `(x,y)`. Eighteen? No: **eight** neighboring pixels, ordered lexicographically by `(y,x)`, graph edges stored undirected. Full source graph original V17 retained as immutable control. Both A/B must preserve all original skeleton nodes; no new skeleton pixel.

**A — triangle-aware diagonal edge suppression:** for every diagonal edge between `(x,y)` and `(x+dx,y+dy)`, `abs(dx)=abs(dy)=1`, suppress it if either orthogonal bridging pixel `(x+dx,y)` or `(x,y+dy)` also lies on the original skeleton. This only removes **graph edges**, not pixels; never suppress an isolated diagonal connection. Trace maximal edge-disjoint chains from degree!=2 nodes followed by pure cycles deterministically; reject chains with Euclidean arc length <4 source pixels; RDP tolerance0.6px. This is a new adjacency graph, not a claim to be Skan/Guo–Hall.

**B — A plus junction tangent pairing before the short-chain cutoff:** construct all A chains first, including length<4. At each graph junction degree>=3, gather unpaired chain half-edges ending at that exact source pixel. For each halfedge compute outgoing tangent from the junction to the farthest member at **up to 3 graph edges away along that chain**, normalize. Pair only two different halfedges with cosine <= `-0.9063077870366499` (angle >=155 degrees) and never select identical halfedge. Enumerate candidate pairs by increasing angular error `(1+dot)`, then lexicographic chain/endpoint ID; choose greedy one-to-one matching. No "bridge" across nonidentical coordinates; paths are stitched by reusing the exact common junction pixel, not adding new pixels. Chains not paired remain separate, pure cycles untouched. Traverse stitched routes through the matching so each **underlying A chain appears in exactly one route**, deterministic lexicographic starting halfedge; reject final routes <4 source pixels (after pairing only). A new route with more than128 RDP vertices is split at shared points. RDP epsilon0.6 as V17. Fail-closed on edge duplication/loss, two-way malformed match, quotas >4000 paths or >30000 vertices or non-finite/out-of-bounds coordinates.

**Fixed output preview:** logical 460×240, contain source200×320 to ROI150×240 at (155,0), source points map `x*.75+155,y*.75`; brush parameter width1 and OpenCV `LINE_8` thickness1, constant RGB(49,38,43).
