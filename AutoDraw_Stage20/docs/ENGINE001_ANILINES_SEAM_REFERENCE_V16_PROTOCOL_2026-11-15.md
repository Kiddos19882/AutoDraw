## Эталон и происхождение

Эталон должен быть размечен человеком по **только исходному RGB 200×320**, не по AniLines/FDoG overlay, и до просмотра методов и метрик. Чтобы сохранить независимость, аннотации должны быть сделаны независимым проверяющим, не видевшим результатов V14/V15. Разметка имеет два обязательных прозрачных слоя PNG **ровно 100×189** для исходного ROI:

- `seams_positive.png` — только согласованные структурные штрихи настоящих швов, складок, лацкана и рукава **пиксельными центральными линиями 1 px** (255 означает утверждённую линию, 0 отсутствие утверждения). Это не сплошная тёмная маска и не Canny.
- `definite_nonseam.png` — проверенные регионы, в которых любая обнаруженная линия заведомо ложна для цели **jacket-only**, включая уверенно выбранные участки фона и других элементов (255 означает negative, 0 unknown). Это частичная маска экспертно размеченного отрицательного пространства, **не полное определение всех ложных пикселей**.

Не пересекать эти два слоя и не ставить 255 по умолчанию на неизвестных пикселях. Без источника/имени и версии разметки, даты, SHA256 двух PNG, количества положительных и отрицательных размеченных пикселей статус `BLOCKED: ANNOTATION_MISSING`; пустой любой слой **fail-closed**. Нельзя считать алгоритмический контур самого AniLines, цветовую маску или Canny независимым эталоном. Отдельный JSON-манифест связывает идентификатор аннотации, источник SHA, ROI, тип blind review, версию и SHA двух PNG; недостающий манифест — BLOCKED.

## Предобъявленные метрики оценки (без quality PASS)

Фиксировать обе бинаризации, не менять V14/V15 в истории. Для V16 **только** кандидаты `gray<128`:
1. `positive_recall_1px`: доля 255-пикселей эталонных швов, поддержанных кандидатом в квадратной окрестности 3×3 (Chebyshev 1 source px). Это *не* global Canny recall.
2. `nonseam_candidate_density`: доля утверждённых negative-пикселей, покрытых кандидатом. Это не глобальная 1−precision, поскольку unknown исключён.
3. `supported_candidate_fraction_on_labeled_pixels`: доля кандидатов в adjudicated positive±1 и negative; считать только по уникальным пикселям известной positive-or-negative области, unknown не считается true positive или false positive. Показатель только диагностический.
4. `positive_gap_components`: число положительных 8-connected компонентов, для которых покрытие в пределах1px меньше половины; это признак разрывов, но не человеческий recognition score.
5. Полные счётчики исходных/последующих кандидатов, сохранённых/отсечённых пикселей, отдельные per-region показатели и SHA всех входов/выходов.

Fail-closed если positive и negative пересекаются или negative даже после расширения positive на 1 px попадает в конфликт; если неизвестна размерность или source/model SHA; если нет независимой ground truth; если отсутствует один baseline. Не называть fraction на частично размеченных пикселях полным semantic precision. **Никаких фиксированных acceptance thresholds по результату на данном рисунке.** Целевой критерий реальной будущей системы — узнаваемость/отсутствие лишних линий без потери швов на *другом заранее не виденном изображении* и только затем отдельный native Egret + per-color safety + unchanged >=99% coverage, 3 logical px diagnostic bound, game exact CHALK = post.pointCount−pre.pointCount, независимое E5.
