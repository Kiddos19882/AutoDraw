## Candidate methods (predefined, no tuning after outcome)

Connectivity: **4-connected**, identify existing same-engine-index component of **area 1–3 logical pixels**, in row-major color/component scan. Allowed destination = already selected32, **4-neighbor touching donor** in the frozen M0 map, never diagonal-only, no invented RGB. Only merge a complete original component, never split. Candidate target per donor ranked by smallest source RGB CIEDE2000 sum over component, then largest 4-neighbor contact count, then smallest engine index. For each component compute original-RGB CIEDE2000 to current vs donor at every pixel and to any touching *neighbor original RGB* (border evidence). Reject if original hue/chroma would acquire new unsupported excess compared with current, or if donor is not source-supported. Screen candidate replacements against frozen source logical RGB, not smoothed/quantized preview. Apply disjoint component decisions from the **frozen** M0 snapshot, one simultaneous pass; no recursive paint propagation. If components touch/overlap or donor changes, resolve by stable row-major one-pass reservation and report skips. Determinism and idempotence of no-op are unit contracts.

**Always-protected:** original RGB logical bright `min(R,G,B)≥245` forced WHITE6, all `female_face_eyes`, `male_face_eyes`, `hands` fixed ROIs from existing P1 (fully protected), original high structural detail mask from `full_features(original)[protected]` reduced to logical with **BOX any**, and original `original_edge_map` Sobel90; zero changed protected pixels (strict assertion). These are source-only masks, not old V44. Border guard validates mean original-neighbor CIEDE2000 across 4-neighbor component edges; donor-color fidelity computed vs ORIGINAL, never source medoid.

- **S_STRICT:** morphological 1-pixel 4-neighbor expansion of the protected original mask; any changed pixel in expanded protection rejected; mean per-pixel donor ΔE00 vs current ≤0.0, worst per-pixel increase≤1.0; original neighbor-border mean ΔE00 ≤10.0.
- **T_LOCAL:** exact (not dilated) protected original mask; mean donor ΔE00 increase ≤1.0, worst per-pixel increase≤2.0; original neighbor-border mean ΔE00 ≤14.0.

Both methods cap changed pixels at **360 logical pixels (1% of 36,000)** per image; allow only complete components. Rejected proposals stay as original M0. Order, limits, masks and thresholds fixed before running the image. Never relabel a source-backed microdetail to improve island score.
