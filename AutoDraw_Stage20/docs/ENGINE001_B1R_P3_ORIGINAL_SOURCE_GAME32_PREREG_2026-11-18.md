## Frozen ablations: 4×2 = eight game32 *screening* variants

For **each** `C_096+D_BORDER`, `C_096+D_COMPONENT24`, `C_192+D_BORDER`, `C_192+D_COMPONENT24`, two mapping methods, **no additional ablations**:
1. `N_NEAREST`: CIEDE2000 nearest of the accepted P2D `NEAREST` logical RGB to 32 actual swatches at every logical pixel, deterministic argmin ties in JSON order. For original source pixels min RGB≥245, force palette pure-white id30. No random dither, no forcing a selected color from old G32 image. This yields an actual 32-swatch **logical model preview**, not brush rendering; quantify false chroma, hue and quality.
2. `S_GUARDED`: at each logical pixel select smallest **CIEDE2000 distance between P2D target RGB and allowed actual swatch**, but allow only game swatches satisfying **simultaneously**:
    - If original logical minRGB≥245, only pure white ID30.
    - Else perceptual source-grounding from **original logical RGB**, not P2D: `C_game≤C_original+12`; for `C_original≥12 and C_game≥12`, circular Lab hue difference≤45°; for original `C_original<12`, at most `C_game≤C_original+12`.
    - Global source fidelity `ΔE00(original,palette swatch)≤20` and target fidelity `ΔE00(P2D_target,palette swatch)≤20`.
    - Candidate swatch must be from exact pinned 32 RGB. Missing any allowed swatch => **abstain index -1**, never silently force an unrelated vivid pink. RGBA unresolved pixels alpha0 plus separate unresolved mask; a contrast overview may show unresolved as neutral gray with legend, but **such overview is NOT a playable palette32 image**. Never claim abstention as white paint, coverage, or executable path.
    - If allowed, choose argmin by target ΔE00, ties by palette order. Log rejected swatch count by chroma/hue/source error/target error; avoid global ban of genuinely original pink.

`N_NEAREST` all indices0..31. `S_GUARDED` indices -1..31; all *assigned* swatches must be exact real game colors; unresolved diagnosis is distinct from actual game. No new added 32-color palette learned from old maps. Output PNG: original; four accepted source-RGB P2D (discrete and LANCZOS); both palette mappings per variant; per-color source pixel allocation and unresolved geometry; original/face/eye/hand crops; 4× candidate comparison panels and one combined overview; frozen prereg report with CI SHA, source and palette SHA, versions, metrics, linked sha256 hashes.
