## Пять arms и строго единичная переменная

1. `STRICT_P4D8`: неизменный P4D8 cumulative native acceptance: действительно 0 foreign source changed alpha>=24, 0 исходно-белых alpha>=24, новый correct0→1, source sample0→1, zero lost1→0. Должен воспроизвести исторические 16/21 и17/307, иначе весь эксперимент BLOCKED.
2. `SOFT_1_BACKING`: тот же полный native результат, но разрешить **<=1** физического original-source foreign `changed AND after.alpha>=24` за один принимаемый stroke.
3. `SOFT_2_BACKING`: аналогично <=2.
4. `SOFT_3_BACKING`: аналогично <=3.
5. `ADAPTIVE_RGB12_REPAIRABLE`: max foreign<=2 backing на пробный stroke; для КАЖДОГО изменённого original-source foreign backing pixel расстояние до исходного sample Chebyshev <=1 logical, максимальное изменение композитного (на белом) реального RGB `max(abs(after-before))<=12` на канал, и затронутый исходный owner имеет **зафиксированный P4D7 sample на расстоянии<=1 logical от этого пикселя**. Последнее означает только **потенциальный кандидат докраски**, НЕ доказанную фактическую ремонтопригодность. Нет новой белой краски alpha24, потерь 1→0 и outboard spill; обе soft и adaptive сохраняют исходную картину, собственный RGB, sample gain и size1. Никаких новых фаз (P4D10), направлений или widths>1 здесь нет.

Для каждого режима одинаковые P4D8 сортировка/выбор вариантов (сортировка по isolated native correct, alpha1 foreign, stable sample/phase), исходные 21 sample, 66 вариаций/пиксель, only P4D7 single native safe/correct candidates; при каждом trial **полностью перерисовать исходную Egret BoardPane** все принятые штрихи + новый. Текущую 0/1 state recompute из actual native cumulative RGBA. Не объединять cached stamps. Rejected trials сохранять. Отсутствие потери уже correct cells и нулевая alpha24 краска на исходно-белом — HARD gate для всех arms. Данные об aggregate source-protected foreign и окончательном цвете всегда сохранять; допустимость soft/adaptive измеряется отдельно от **существующего утверждённого protected foreign=0** и far>3logical0. **В этом protected face ROI всякая реально ненулевая source-foreign alpha24 даже в 1 backing = строгое качество FAIL**, несмотря на scientific улучшение; «гипотетически мягко принят» **НЕ production PASS**. Внедрение допусков/изменение safety запрещено без новой независимой визуальной validation и отдельного принятого решения.
