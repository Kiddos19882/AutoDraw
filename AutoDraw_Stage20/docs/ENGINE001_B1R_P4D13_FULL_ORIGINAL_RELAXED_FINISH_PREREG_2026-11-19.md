## Исследовательские вопросы и фиксированный план

- **H1:** source-only full-art relaxed painting can cover more nonwhite owner-correct logical pixels after at least one adaptive residual-pass versus native full-art initial P4D0 plan, with all original-source pixels actually scored, without stopping on small neighbor overlap. **H2:** full-art relaxed result will have >0 measurable native white ink or protected source mismatch (risk); record even if visually small. Не менять заранее заданные thresholds/quality gates для улучшения научного статуса. H1/H2 may FAIL.
- Рассчитать с неизменённого оригинала **оба** свежих E и F, независимо, с настоящим game palette / game geometry. План `p4d0.adaptive_unbounded(index,game)`: все исходные owner компоненты, widths1..10, все цвета без quota. Он использует cv2 только для предложения/модельного поиска; **native confirmation исключительно real Egret**. Зафиксировать планы JSON и числа stroke widths/owners/points.
- **Начальная полная доска:** `p4d0.patch_renderer_in_memory` применяется ТОЛЬКО к проверенной raw archival test-fixture копии внутри scoped context `p4d0.patched_test_renderer`, обязательно rollback bytes. Реальная итоговая BoardPane сцена через Selenium Firefox/real Egret WebGL `renderP4A2BrushWidths1to10Probe`, raw full native RGBA PNG. Это исследовательский обход тестового ограничения на число вершин, не изменение игры или реального лимита CHALK. Зафиксировать blank scene alpha0.
- **Разрешить смешение/задевание** независимо от protected source owner. Не отклонять штрихи из-за новых foreign alpha24, накопленных наложений, пропусков или 1→0. **После полного native снимка** построить `state` каждого исходного небелого логического пикселя (5/9 backing color owner correct). Для оставшихся `0` предложить **простые width1 горизонтальные contiguous owner runs** только внутри исходной owner-карты по действительным остаточным0 (source-aligned, no invented color), одним `p4d0._stroke(...,width=1)` на каждый такой run. Ровно один полный native cumulative replay на каждый **из трёх** repair rounds, без per-stroke strict rejection. Выбор очередного residual по свежей **реальной** RGBA после предыдущего раунда, не исходя из модели. Три раунда — конечный экспериментальный бюджет, НЕ гарантия результата99% и НЕ hard limit production. Если остаточных нет, раунд отмечать SKIPPED; если нет новых корректных или ухудшение — всё равно сохранять raw, не выдавать научный PASS.
- **Контроль**: `p4d0.first_scanline(index,game)` нативный width2 full original в качестве честной простой альтернативы; сохранение raw и сравнение final. Дополнительно сохранить raw baseline `adaptive_unbounded` до repair, 3 incremental raw stage, target owner palette, оригинал, визуальный full-art contact sheet, enlarge face ROI/white leakage/error maps. Не накладывать искусственный глобальный тёмный контур из истории. Все финальные E/F native stages должны быть напрямую измеренными реальным Egret, не Pillow-синтетикой.
- **Измерения:** native logical correct0/1 per owner and total nonwhite denominator, residual0, new0→1/lost1→0 по раундам, alpha24 ink на original white и outside source, native RGB mismatch delta>32, protected critical face/eyes overlap and per-color accuracy, coverage/leakage, total true renderer strokes/vertices (NOT_CHALK). Original image perceptual recognizability — user visual review pending; E3 native preview does not equal E4.
- **Критерий полного эксперимента E3:** обе full E/F source native scenes и raw PNG завершены, 3 repair rounds или documented SKIP, native blank, reproducible manifest SHA, report with baseline vs final, comparison PNG and all failure/mismatch counts; independent ZIP verification when accessible. Качество отдельно PASS/FAIL по frozen owner>=99%, protected foreign0, far>3logical0, critical face and user visual review. Никаких ретроспективных adjustments.
- **Не измеряется:** E4 actual game, E5 independent image-quality verification, run-bound exact `CHALK=post.pointCount-pre.pointCount`, game executor. Если аппаратный лимит, native renderer, browser или upstream source не позволяет исполнить полный run — сохранить partial and BLOCKED честно. Не считать модельный preview E3.
