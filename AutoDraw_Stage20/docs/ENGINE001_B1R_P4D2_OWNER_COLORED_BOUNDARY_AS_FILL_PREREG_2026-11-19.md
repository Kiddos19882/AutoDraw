## Frozen transformation: inner owner-colored boundary integrated as paint

For each logical source `index[y,x]=owner` with `owner != 6`, define `is_inner_boundary` iff one or more **four-axis neighbours** up/down/left/right lies outside the same owner (outside logical 240x150 also counts). This is a 1-logical-pixel **inner** boundary: never seed boundary geometry from another swatch, a global Canny mask or P4D1 dark contour. Split each owner's inner-boundary mask into maximal horizontal same-owner runs, in ascending y/x; each run becomes an ordinary **width1** two-point native Egret fill stroke using the same source owner `colorIndex` and exactly `game_palette[owner]` packed as `colorRgb`. Stroke centerline `(x0+.125,y) → (x1+.375,y)` in logical source ROI offset155. Each boundary stroke must lie entirely on same-owner source-index pixels at its control points; no paths across other owners or white pixels. One-pixel runs are valid, not dropped.
- `ADAPTIVE_UNBOUNDED`: retain entire P4D0 owner-group paint sequence. Immediately **after each owner's original paint group**, insert that owner's boundary fill strokes (same owner/RGB). No global additional layer or sorting whole image by boundary. This is integrated owner-by-owner.
- `FIRST_SCANLINE`: preserve entire P4D0 scanline base paint sequence; insert boundary strokes belonging to the exact horizontal source row/run **immediately after that parent run**. Still y0..239/x0..149; no global contour after all scanlines. No change to P4D0 paint width, points, colors or count. No blanket "dark outline" and no independent contour drawing call. Number of source boundary strokes comes from source geometry (not budget). Provenance must prove every boundary owner/RGB and source pixel run.
- Stroke IDs are freshly renumbered; no counts/vertices caps for this P4D2 diagnostic, using existing narrow scoped `P4D0.patched_test_renderer` to bypass frozen test-only preflight caps, then original bytes restored. Real game cap and CHALK remain untested.

## Experimental design, decisions and risks

- E/F × P4D0 adaptive/scanline × **PAINT_ONLY_CONTROL** (exact original P4D0 paint plan) versus **OWNER_COLOR_BOUNDARY_AS_PAINT** (identical paint plan plus owner-matched inner edges) => **8 real native Egret full-color scenes plus real empty alpha0 control**. Unit tests prove no dark-constant color, row ordering, owner neighbor masks, full edge coverage, original paint subsequence, true P4D0 planner reuse, zero stroke truncation, determinism, all owner strokes match palette and source run.
- Hypothesis H1: colored inner boundary strokes reduce P4D0 native any-ink boundary gaps and improve RGB similarity to source compared to paint-only without the global darkest outline. Alternative H0: too many small source boundaries cause more leaks and degrade RGB/color area while preventing dark-global contour. **Negative results remain valid and reported.**
- Real native pixel evidence: alpha>=24 any-ink target coverage, count missing, actual drawn ink on white-index pixels, composite maxchannel RGB difference<=32, wrong-pixel masks, per-scene native PNG 1380x720 and logical ROI 450x720, original RGB, E/F chosen index and palettes, deterministic full JSON stroke plans and provenance, four side-by-side images (original/index/P4D0 paint-only/owner-colored bound-in-fill). Blank alpha0 and manifest member SHA256, one ZIP. Numeric improvement requires correct-color closeness strictly improve AND no increase in native white background ink; other outcomes flagged `NO_NUMERIC_IMPROVEMENT`. Visual faces/eyes/hair/hand approval separate; do not infer aesthetic approval from count/CI.
- P4D2 does **not** assert >=99% per-owner *same-color* coverage, 0 protected foreign, 0 beyond3logical without per-owner native testing; no relaxation of accepted quality gates. Composite any-ink not same-color. E3 Egret is *not* E4 gameplay; exact run-bound `CHALK=post.pointCount - pre.pointCount` E4/E5 NOT_RUN; all synthetic vertices and stroke count are NOT game CHALK. Production promotion prohibited until independent accepted quality and gameplay.
- Risk: 4-neighbour inner boundary may contain ~8k small runs E/F, widths1 anti-alias at adjacent swatches, so could increase foreign ink or undo fill color layering. Preserve full failures, no silent posthoc stroke removal or coordinate clipping.
