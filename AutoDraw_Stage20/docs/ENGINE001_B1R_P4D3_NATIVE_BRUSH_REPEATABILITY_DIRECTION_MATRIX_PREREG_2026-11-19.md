## Metrics and prespecified decisions
- `within_scene_ten_translated_exact_rgba`: all 10 isolated same-geometry strokes have exactly identical native ROI RGBA; report mismatch pixel count and max absolute RGBA difference per width/angle/length. This measures same-render stable rasterization at integer translated coordinates, not game movement noise.
- `whole_scene_two_replays_exact_rgba`: two independent JS render invocations match every RGBA backing pixel exactly. Any mismatch is **DETERMINISM_FAIL**, do not use a tolerance to call PASS. One blank alpha0 native control required.
- `overlap10_vs_single`: exactly equal native relative ROI or count RGBA changed px, alpha>0 and alpha>=24 area, rgba differences; never conflate alpha accumulation/overdraw with random geometry. `angle+180` direction reversal exactness is diagnostic, report mismatch even if 10-copy tests pass.
- For directional shape variation measure total ink pixels, bbox, alpha histogram, opacity, static ROI. Across angles distinct footprints are expected, **not nondeterminism**.
- Primary narrow PASS: 480/480 cases genuine native renderer, 10/10 independent footprint equality, 2/2 whole-scene exact equality, zero blank; with 80/80 stress exactly repeated replays separately. If some differ, report **FAIL** by case and width/angle. Near-edge / color collision may yield deterministic clipping and color compositing; not automatically FAIL if repeated.
