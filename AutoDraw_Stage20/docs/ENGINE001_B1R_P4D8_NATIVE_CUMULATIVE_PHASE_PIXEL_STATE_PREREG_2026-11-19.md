# ENGINE-001 / B1-R P4D8 — последовательная native 0/1 покраска фазовой кистью1

**Experiment ID:** `ENGINE001_B1R_P4D8_NATIVE_CUMULATIVE_PHASE_OWNER_PIXEL_V1`. **E0 prereg, 2026-11-19, ДО создания P4D8 кода и CI.** Пользователь 2026-11-19 разрешил разработку, тестирование и документирование. Только отдельный научный runner, тесты и GitHub Actions; запрещён незаметный production promotion, изменение master/игрового движка/контуров/CHALK estimator. В P4D8 мы проверяем **первый последовательный** шаг после P4D7, а не объявляем готовую заливку изображения.

## Baseline, первичные данные и гипотезы

- Frozen B1-R P3D `C_192_D_COMPONENT24` E/F original user RGB SHA256 `07cc4568cb5e90d9514bc6f6c2112fee623f87f8fd0cea02fa517b04108e502a`, 32 выбранных RGB из настоящей engine128 palette. Игра bundle git blob `46cc74de00b6cb5d207b1e1a2ffcd81613b6d388`, Egret5.4.1 BoardPane/WebGL renderer git blob `76d950e0a8911888a9df3b675b866519ecf7bba4`. Board 460×240 logical, native 1380×720, source index 150×240 при смещении X0, 3× backing.
- [P4D7 E3 CI44428805429](https://github.com/Kiddos19882/AutoDraw/actions/runs/44428805429), fixed SHA `fe036d43ad7c28f060c6f032ef81c583e63d5fe2`: 21/21 изолированных контрольных пикселей обладают хотя бы одной safe/correct фазой из66, но отсутствие совместной интерференции **НЕ доказано**. [P4D5 CI44424883298](https://github.com/Kiddos19882/AutoDraw/actions/runs/44424883298): 10/307 correct, 297 residual; [P4D6 CI44426078599](https://github.com/Kiddos19882/AutoDraw/actions/runs/44426078599): 1/307 correct, 306 residual; оба алгоритмически FAIL. Метрики P4D5/P4D6 — исторические контроли, не повторно измеренные P4D8.
- Frozen source crop female_face_eyes `(x0,y0,x1,y1)=(40,45,64,69)`, 24×24, 307 nonwhite target, 269 original white, 20 небелых source owner indices. E/F index map в **этом** ROI битово идентичны, поэтому P4D8 измеряет только E и не выдаёт её за две независимые проверки. Взять **те же неизменные 21 позиции**, что в P4D7. Защищённые source-critical пиксели включают весь crop, поэтому для всех последовательно принятых штрихов запрещён всякий чужой **alpha>=24** на настоящем исходном владельце (включая белый), а не использовать допуск 3 logical в protected ROI.
- **H1:** изолированные фазы P4D7 можно безопасно составить в общую реальную Egret-сцену, повысив число правильно закрашенных source-owner pixel относительно 10/307 P4D5 без нового protected foreign и при реально измеренном 0/1 feedback. **H2 (более строгая цель):** финальный native cumulative результат достигает всех 21/21 *фиксированных* контрольных пикселей. **H0:** накопление alpha, цветные пересечения или поведение native-порядка не позволяет композицию, даже если 21/21 изолированно достижимы. Отрицательный/частичный результат сохранять как FAIL/PARTIAL, не менять пороги после результата.

## Единственная экспериментальная переменная

Продолжить [P4D7 E0](ENGINE001_B1R_P4D7_NATIVE_SUBPIXEL_PHASE_FEASIBILITY_PREREG_2026-11-19.md) без правки его runner. Для каждой из21 frozen source координат повторно получить **66** изолированных настоящих Egret width1 штрихов (64 точных фаз в сетке8×8 и 2 исторических контроля), ровно 1386 raw isolate плюс blank через **неизменённый** P4D7 runner; сохранить все raw PNG и JSONL без «модельного сдвига» масок. В P4D8 использовать только строки isolated native `phase_feasible=True`; предсказать индивидуальную пользу по **действительно измеренному** числу source-correct логических пикселей, затем на каждом шаге делать отдельный **полный native BoardPane перерендер всех уже принятых штрихов плюс один кандидат** с реальными оригинальными (не сдвинутыми) float координатами.

**Порядок:** из ещё незакрашенных фиксированных контрольных точек выбирать лучший оставшийся изолированно допустимый штрих по (1) большему isolated owner correct, (2) меньшему alpha1 foreign, (3) фиксированным sample ID и phase name для стабильного tie-break. После каждого реального trial обновить всю 24×24 current state из полного Egret RGBA (owner RGB delta<=32 на >=5 из9 backing и alpha>=24). Принимать штрих, **только если** его исходный sample перешёл 0→1, число правильно покрытых целевых пикселей на ROI строго увеличилось, ранее корректные target 1 не потеряны, на source-foreign backing не появилось изменений с текущим alpha>=24, на исходном белом canvas нет alpha>=24 и внутри исходного crop не загрязнён protected owner. Искусственные границы crop **не** являются foreign: тот же оригинальный owner за crop допустим. Повреждения/alpha1 foreign учитывать отдельно даже при отклонении; при отказе оставить current/plan неизменными. Уже правильные samples пропускать. Исчерпать допустимые альтернативы до завершения или конечного числа isolated-safe вариантов (нет hidden cap на strokes в пилоте); отрицательные trial сохраняются. Повторно отрисовать финальный план, сравнить raw RGBA и метрики exact.

**Безопасность:** hard gate для нового чужого цвета в исходной защищённой face region `alpha>=24: 0` на **каждом** accepted trial (сравнение native before/after, owner mask полного original source, включая original white). Такой gate в этом полностью защищённом crop сильнее `farther_than_3logical=0`; не распространять автоматом выводы на незамороженные другие ROI. Сохранить original source, точный renderer, Engine swatch, NO dark contour, без G32/V44 seed. Ни P4D7 isolated mask, ни OpenCV, ни геометрическая капсула не считаются native подтверждением итогового штриха.

## Завершение, артефакты и уровни evidence

- **E2:** фиксированная source selection и66 phases, независимое накопительное native delta-safety на synthetic RGBA, 0/1 gain и loss, deterministic tie-breaking, reject foreign/white/negative net, fail-closed source/renderer/prereg/provenance. Никакой E2 тест не считается нативным quality proof.
- **E3:** один fresh P4D7 isolate crosscheck и один реальный P4D8 full-board progressive native Egret run на **том же crop E**, обязательно native blank. Хранить все P4D7 raw PNG, каждый P4D8 accepted/rejected full cumulative PNG, append-only trials JSONL, exact owner/phase coordinates, frozen source E/F crop indices, final before/after counters, repeat replay, comparison PNG, SHA256 member manifest и один ZIP/Actions artifact. Все результаты даже FAIL сохранить и корректно сообщить.
- **Primary numeric:** final correct из 307, residual 0, fixed sample correct из21; monotonic 0→1, loss1→0, source-foreign delta alpha24, white alpha24, rejected trial counts, native plan widths/point count. **Secondary:** preview recognizability (face/eyes), per-color coverage внутри crop, alpha1 leakage, number of strokes and repeatability. **Зафиксированная цель:** H1 >10/307 and zero protected foreign; H2 21/21 fixed samples with zero protected foreign. Заранее неизвестно, будут ли они достигнуты; не заменять пробы принятыми штрихами.
- **Не проверяется:** другая original E/F ROI, полная картина owner>=99/без protected foreign/far>3logical, все размеры кисти 1–10 (здесь только width1), реальная игра E4, независимая E5 и точный run-bound `CHALK=post.pointCount-pre.pointCount`. Всё это остаётся OPEN/NOT_RUN и требует дальнейших отдельных экспериментов.
- **Основной риск:** отдельный P4D7 stroke был safe по isolated alpha24, но два соседних полупрозрачных края при последовательной отрисовке могут создать alpha24 на чужом owner. В таком случае зафиксировать REJECT вместо ослабления порога.
