## Пререгистрированные arm, единственная переменная — порядок

Один раз вновь получить **1386** настоящих isolated width1 Egret strokes + blank через неизменённый P4D7 runner; включить только `phase_feasible=True` с source owner foreign alpha24=0 и правильным sample 5/9. Не изменять P4D7 point coordinates, palette, выбранные 21 sample, 24×24 ROI, alpha threshold24, RGB tolerance32, 5/9 criterion, native session, candidate pool, fallback, P4D8 `trial_metrics`/acceptance, whole-board renderer и isolated ranking внутри одного sample.

Из одного и того же измеренного pool и источника сравнить **3 детерминированных порядка**:
1. `BASELINE_P4D8`: неизменённый original P4D8 `rank_candidate` (большее isolated owner correct, затем меньше alpha1 foreign, затем sample_id/phase). **Frozen parity gate:** этот arm должен повторить 16/21 samples, 17/307 correct,16 accepted/21 trial из CI44470625000. Не PASS если drift; P4D8 исторический отчёт не переписывать.
2. `FIVE_FAILED_SAMPLES_FIRST`: строго заранее выписанная priority-группа `OWNER011_X046_Y046`, `OWNER113_X046_Y045`, `OWNER116_X050_Y057`, `OWNER123_X054_Y045`, `OWNER127_X062_Y045` первая, остальные в исходном P4D8 ranking; внутри группы тот же original P4D8 rank. Проверяет инверсию соседства без новой геометрии или tolerance.
3. `SOURCE_OWNER_DESCENDING`: тот же кандидатный набор сортировать по числовому owner убыванию и original rank в рамках owner; контроль общего влияния порядка, не только post-hoc пяти случаев.

**Cumulative strict rule для всех arm:** каждый trial — новая фактическая BoardPane/WebGL перерисовка принятой последовательности + ровно один phase stroke, не union model stamps. Состояние всех 307 target pixels пересчитать из native raw RGBA (>=5/9 owner RGB delta<=32 и alpha24). Принимать **только** если target sample новая 0→1, strict new correct gain>0, lost1→0=0, вся changed foreign-owner backing при alpha>=24=0 и original white ink alpha>=24=0. Все rejected raw native PNG и JSONL append-only сохранить. Подтверждать только source-original true-owner, 3logical beyond не ослаблять; весь protected crop не допускает чужой цвет независимо от расстояния. В каждом arm после финала отдельный native exact RGBA replay; любые ошибки/differences fail-closed. Не пересчитывать CHALK по vertices.

## Гипотезы, границы, критерии

- **H1:** хотя бы один альтернативный arm увеличит количество final correct fixed samples **строго более 16/21**, сохраняя strict foreign/lost/white0; **H2:** хотя бы один увеличит total original target correct **строго более17/307**; **H3:** один из заранее фиксированных альтернативных arm даст **21/21** sample правильно (с текущими safety gates). Даже H1/H2 PASS — только ROI-scoped E3 диагностика, не overall image quality.
- Обязательный отрицательный результат: если priority/reverse не улучшают score или создают новые нарушения, сохранить все trial PNG и точные reasons, не менять selection или thresholds post-hoc; научный результат FAIL/PARTIAL, даже если CI technical PASS.
- **E2:** fail-closed frozen source and p4d7/p4d8 pinned modules, order permutation only, all 21 known sample IDs, no foreign safe loophole, fixed tie-break, baseline parity and no production code. **E3:** одна fresh P4D7 full isolated suite, три native cumulative arm with blank per arm and real rejected attempts, negative evidence, accurate new/lost/foreign/white, original E/F index maps/preview PNG, metrics by arm, exact replay, SHA256 manifest, ZIP. Один CI workflow; один archive, include all scenes and source/provenance.
- **NOT_RUN:** другие оригинальные ROI, весь рисунок own-color≥99%/protected foreign0/far>3logical0, кисти2–10, игра E4/независимая E5, exact run-bound `CHALK=post.pointCount-pre.pointCount`, production. Нельзя принимать выбор порядка из 21 точек за готовое решение для полноформатного AutoDraw.
