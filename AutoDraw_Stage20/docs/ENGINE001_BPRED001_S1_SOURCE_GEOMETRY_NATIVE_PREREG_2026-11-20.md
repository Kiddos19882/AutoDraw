## 1. Hypotheses / frozen effectiveness gates

- **H1, source geometry:** `M0` центр=(start+end)/2 в logical; `M1` центр=(start+end)/2 + `(0.5,0.5)` только при widths1,3 (на основе реального Egret5.4.1 `CanvasRenderer.renderGraphics`, [P4D14](ENGINE001_B1R_P4D14_EGRET_GRAPHICS_HALFPIXEL_CENTROID_PREREG_2026-11-19.md)). На **120 новой CALIBRATION native scenes ×3 copies=360** stroke centroids: mean error `M1` для **72 width1/3 observations** должен быть **≤0.5×** M0 mean и **≤0.20 logical px**. Если не выполнено — `H1 FAIL`, сохранять raw диагностику. Не смешивать с pixel-exact footprint.
- **H2, unchanged widths:** для остальных widths2,4,5,6,7,8,9,10 модели M0 и M1 обязаны давать **точно идентичные** центры и error scores для каждого из **288** observations. Если нет — `H2 FAIL`.
- **H3, scope diagnostic:** bounding box одной непрерывной идеальной капсулы radius=width/2 (+ native source shift при M1) используется лишь как model-only **potential bound**. Отдельно считать количество физических alpha1/alpha24 пикселей за рассчитанным bbox без подбора margin posthoc; любое нарушение фиксировать, **bbox fidelity не является S1 acceptance gate** и не даёт permission для production. Для origin/scale transforms проверить exact `x/y physical = logical×3` на pinned BoardPane. Искажение координат, ROI overlap, неправильное source binding — `BLOCKED`, не H1 PASS.
- **Технический gate E3:** только настоящий archived Egret5.4.1 BoardPane/WebGL на pinned Firefox159.0/Windows, `blank` zero-alpha, 120/120 CALIBRATION scene PNG/JSON/raw order + matching per-scene SHA, full manifest SHA, exact source blobs, no BLIND/CONTROL render, deterministic parameter matrix and 360 native measured nonempty crops. E3 technical PASS и H1/H2 verdict **независимы**.
