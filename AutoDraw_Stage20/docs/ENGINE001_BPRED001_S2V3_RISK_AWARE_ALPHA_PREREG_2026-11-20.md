## Гипотеза и одна фиксированная модель

**Причина эксперимента:** M2 `area8` alpha24 на 120 CALIBRATION scenes достиг IoU .9892986132, но остаются 2167 FP и559 FN; M3 isotonic снизил FP до1315 ценой FN1237 и MAE ухудшения. Требуется определить **область неопределённости**, а не подгонять значения alpha одним преобразованием и выдавать pixel-safe.

Режим `M4_EMPIRICAL_ALPHA_GUARD` — только для **положительного** заявления `trusted_positive`, всё иное `UNKNOWN` (включая предсказанный фон: его нельзя считать заведомо безопасным для покрытия). Он **не изменяет M2 alpha0..255**, исходную форму кисти, halfpixel shift, координаты или raster AA. Для **каждой width1..10 и каждого из трёх зафиксированных folds**:
1. Train только две angle families из `{7,73,166}`, exclude целиком третью angle family (как S2v2): F7=train73/166, F73=train7/166, F166=train7/73. 8 train scenes×3 copies для каждой width, 4 test scenes×3 copies. Все3 translated copies принадлежат исходной family; data leakage forbidden.
2. На **всех train pixel** где `(native_alpha>0) OR (M2_alpha>0)` вычислить `absolute_error=abs(int(M2_alpha)-int(native_alpha))` (0..255). Получить `q_w=quantile(error,0.995,method="higher")`, **целый без округления в меньшую сторону**, для каждого fold/width. Train empty/nonfinite/unknown source = `BLOCKED`; no learned angle, phase, color, model source or native target leakage.
3. Для test ROI `trusted_positive = M2_alpha >= 24+q_w`, сравнение в integer (если threshold>255, trusted_positive all false), **все остальные пиксели UNKNOWN**. Никакого confident-negative, никакого model-only assumed safe background. Это только empirical quantile guard, **не математическая/универсальная гарантия**.
4. Отчёт дополнительно фиксирует residual по жёстким исходным предсказанным alpha bins `[0],[1..23],[24..63],[64..127],[128..191],[192..254],[255]`, по width, angle fold, phase pair и 3 absolute copies. В каждом bin считать count, `native>=24` и `M2>=24 but native<24` и средний `abs(pred-native)`. Эти bins — **диагностика без изменения M4 правил**.
5. Идеальная капсула/ширина и RGB owner не вмешиваются. Физические координаты (162×162 ROI, 3× backing), pinned S1 original PNG true Egret, original P4D16 `area8` через test-only adapter, без новых native рендеров. При нераспознанном browser/source/PNG/plan SHA — `BLOCKED`, не использовать surrogate Pillow/OpenCV.

## Зафиксированные до результатов H1–H3, safety gate

**Базовая модель B0:** `M2>=24` = positive (baseline на том же test fold). Сравнить M4 (subset positives, без новых positives) и B0 на полном **held-out CALIBRATION** из 120 scenes ×3 copies; FP = `trusted_positive & native<24`, retained TP = `trusted_positive & native>=24`. Макро усреднять сначала 3 copies/scene, затем 120 scene для долей; FP/TP — physical counts отдельно. H без переопределения по полученным данным:

- **H1: false-positive reduction**: `total_M4_FP <= 0.10 * total_M2_FP`. Если denominator=0, H1 PASS только если M4_FP=0, иначе FAIL.
- **H2: retain useful positive coverage**: `total_M4_TP >= 0.90 * total_M2_TP` (если denominator0 — `BLOCKED`, недостоверная выборка).
- **H3: per-angle generalization**: для **каждого** held-out angle `M4_FP <= 0.10*M2_FP` и `M4_TP >=0.80*M2_TP`; при M2_FP=0 необходим M4_FP=0. Таким образом average не скрывает плохой угол.
- **Независимый safety gate:** `M4_FP==0` на всех 360 ROI **только для provisional calibration zero-false-safe**; если `M4_FP>0`, `pixel_exact_safe=false`. Даже `M4_FP=0` **НЕ** доказывает E5, S4 blind, protected owner safety, full RGB, опасность overlap или честность CHALK; модель всегда `MODEL_ONLY` и production promotion false.

Сохранять `M2_FN` и `M4_FN=original_true_pos - M4_TP`, долю UNKNOWN на native-positive pixels, число принятых positive, per-bin FP/FN/residual. H2/H3 препятствуют тривиальной модели «всё UNKNOWN». Весь E3 native evidence относится только к исходным S1 cached real Egret, а новый S2v3 тест — **E2/CI offline reanalysis**, 0 новых Egret renders.
