## 1. Цель и проверяемые гипотезы

**Цель:** предсказать физическую альфу пикселей отпечатка круглой двухточечной кисти Egret 5.4.1, widths1..10, с учётом absolute coordinates и исходного width1/3 +0.5 logical, без выдачи модели за native renderer. Найти остаточный false-safe/false-unsafe на реальном WebGL output; затем использовать их для исследовательского шага S2b или планирования S3. Модель пока **не** рассчитывает RGB source-over, перекрытия других owners, изломы, points, игровую калибровку и точный CHALK.

**Заморожены три модели, без обучения/параметрической подгонки в этом опыте:**
- `M0_NAIVE` — [P4D16](../tests/run_engine001_b1r_p4d16_canvas_aa_density.py) `predict_alpha(...,"naive")`: бинарная капсула radius=width/2 по физическим центрам без odd-width shift (alpha0/255).
- `M1_EGRET_SHIFT` — та же функция `predict_alpha(...,"source_halfpixel")`: бинарная капсула, +0.5 logical по обоим осям при widths1/3.
- `M2_AREA8` — `predict_alpha(...,"area8")`: исходная shift geometry и 8×8 area integration/64 samples в каждом физическом пикселе, alpha округляется до 0..255. **Это source-calibrated area-sampling baseline, не обученный residual-corrector** и не новая алгоритмическая формула после наблюдения новых сцен. Возможный M3 residual correction — только с новым E0 после сохранения исходных результатов. Никакой нейросети или подбора порога по исходу эксперимента.

**H1: альфа24** — `M2` достигает **macro scene-mean alpha24 IoU ≥0.985** и **улучшает M1 на ≥0.005** absolute IoU на 120 case families (3 копии в каждой, среднее по трём внутри семейства). Оба условия обязательны, иначе H1 FAIL.
**H2: непрерывная альфа** — `M2` сокращает среднее по case families `alpha MAE` в **union (native alpha>0 or predicted alpha>0)** минимум на **10%** относительно M1 (M2≤0.90×M1). Иначе FAIL.
**H3: source shift** — для widths1,3 `M1` улучшает macro alpha24 IoU относительно M0 не меньше чем на **0.025** absolute (24 case families/72 correlated location observations). Иначе FAIL.
**Safety gate (отдельный):** если существует **хотя бы один** FP или FN при alpha24 или alpha1, то `pixel_exact_safe=false` / `MODEL_ONLY`. Средний IoU **НЕ** разрешает executor/production. Native alpha differences и их worst-cases сохранять, даже если H1/H2/H3 PASS. Нулевые FP/FN на CALIBRATION сами по себе не доказывают blind или критические owners.

## 2. Corpus, units, golden reference and method

- **Единственный настоящий native эталон:** [S1 CI44646682797](https://github.com/Kiddos19882/AutoDraw/actions/runs/44646682797), immutable [artifact14589516497](https://github.com/Kiddos19882/AutoDraw/actions/runs/44646682797/artifacts/14589516497), source SHA `f38f2dbfe8dcb45ea57cdcc7cba2302a848286c1`. Он получен на Windows Firefox159.0, original Egret5.4.1 pinned game blob `46cc74de00b6cb5d207b1e1a2ffcd81613b6d388`, reference renderer blob `76d950e0a8911888a9df3b675b866519ecf7bba4`. **Не запускать новые native сцены в S2v1:** это анализ 120 ранее созданных real-native PNG (не новый рендер). Никакие historical P4D3/4/14/15/16/13/18 PNG не добавлять в эту сравнительную выборку.
- **120 frozen `CALIBRATION`**: S0 original [corpus E0](ENGINE001_BPRED001_S0_CORPUS_INVENTORY_AND_SPLIT_PREREG_2026-11-20.md): widths1..10, angles7/73/166°, lengths7/19, phases independent X/Y (1/16,3/16) или (5/16,7/16); в каждой **3 disjoint location** (58,40),(172,120),(286,200) → **360 ROI 162×162 RGBA**. Все 120 `BLIND_HOLDOUT` +10 blind replay controls **не читать/не рендерить и не вычислять их ошибки**, оставить их для S4. Blank из S1 проверять alpha0.
- Использовать ровно **исходные S1 native PNG** `native/<sample_id>/<sample_id>_REAL_EGRET.png`, `_RUNTIME_PLAN.json`, `_PLAN.json`, `CASE_ROWS_APPEND_ONLY.jsonl`, `report.json`. При загрузке проверить каждый исходный member SHA256, S1 report `github_sha`, `github_run_id`, schema, native shape1380×720 RGBA, 3 источника ROI, 120 unique IDs/360 copies, фазы, width, strokes, source-ID adapter and original-plan SHA before any scoring. Missing, corruption, extra files, browser or version mismatch => **BLOCKED**, не заменять синтетикой.
- Вызывать неизменённую функцию `P4D16.predict_alpha(points,width,left,top,mode)` для каждого physical ROI (left=(cx−27)×3, top=(cy−27)×3) и брать alpha из настоящего PNG. Не смещать native PNG или shift повторно; не выбирать центр/ROI после результата. План S1 хранит отдельно source plan и ID-adapted runtime plan; изменён только `strokeId`.
- Единица независимости при агрегировании — **scene case family**, 3 ROI одного case коррелированы. Сначала вычислить метрики по каждой копии/штриху, затем macro-average по 3 копиям **и** по 120 case families. Отдельно отчёт по width1..10, angle7/73/166, длине7/19, phase и каждой абсолютной позиции; сохранить p95/worst. **Не** считать 360 ROI 360 независимыми samples. Ограничение: результаты calibration, не independent generalization.
- Показатели: per-pixel `alphaMAE_union`, alpha≥1 и ≥24 `IoU/TP/FP/FN`, exact alpha byte match в 162² ROI, предсказанные и native alpha nonzero mass, CDF ошибки и false-safe prediction (FP alpha24: модель говорит painted, native нет), false-negative (FN alpha24: модель говорит unpainted, native есть); `uncertain/UNKNOWN` отмечать, если не выполнен safety gate. Не заявлять false-safe относительно чужих цветов: S2 только однокрасочный blank stencil.
- **Формат evidence:** отдельный append-only `CASE_ROWS.jsonl` 120 cases и per-copy TP/FP/FN/MAE, агрегат `report.json`, проверяемые provenance hashes и native sample references, отдельно worst samples; при допустимой стоимости PNG визуализации модели/ошибки для выборки фиксированного индекса ширин1/3/6/10, без визуального cherry-pick после оценки. ZIP каждого существующего PNG **не переписывать**, source-native artifact сохраняется как immutable external parent, результаты S2 публиковать новым Actions artifact с SHA256 всех новых файлов. Новая S2 работа может иметь свой CI SHA; source S1 native SHA не переписывать.

## 3. Статусы и ограничения

- `E0` этот документ **до** исхода. `E1` подтверждён предыдущим source audit и P4D16. `E2` проверки алгоритма и provenance, `E3` исследовательский CI на **существующих реальных Egret E3 пикселях** — не новая native-сессия. `E4` game/Monitor/Bridge и `E5` blind/independent **NOT_RUN**.
- S2v1 **не** разрешает native color compositing S3, blind opening S4, global planner S5 или stroke optimization S6 без продолжения работ по согласованному плану. P4D18 protected original-white/leakage остаётся **FAIL**; P4D19 `DEFERRED`; original B1-R E/F owner quality gates неизменны. `master`, production brush, Stage6, game renderer, Monitor/Bridge/CHALK estimator не менять.
- Следующий шаг после результатов S2v1: если макро-ошибки и FP/FN существенны, сначала зарегистрировать отдельный **S2v2 E0 residual correction** на `CALIBRATION`, не трогая BLIND. В случае достаточной alpha fidelity — переход к S3 compositing по основному плану, но никакого production acceptance по model-only.
