## 3. Fixed competing representations (all RGB integer byte space)

Given true original source owner color channel (C in 0..255), isolated exported alpha byte (A in 0..255), isolated exported straight byte channel (R), and potential hidden physical alpha (a in [max(0,A-0.5),min(255,A+0.5)]/255):

- **F0 original palette-RGB control:** exact expected straight channel (R_0=C). Record (|R-C|), counts >2, max per alpha bin; count any false claim of exact owner color. This is a descriptive negative baseline, not a relaxed original image quality gate.
- **F1 8-bit premultiplied-byte round-trip candidates:** use only `p = floor(C*A/255)`, `p=round_to_even(C*A/255)`, and `p=ceil(C*A/255)`; after each candidate p, `R_1 = clip(floor(255*p/A+0.5),0,255)` for A>0. Report exact mismatch and absolute byte error for each of the 3 **preselected** p modes separately, never select the best mode *per pixel* as a promoted universal predictor. For A=0, RGB is UNKNOWN/transparent control; no division by zero.
- **F2 alpha-interval/premult lattice envelope:** enumerate the alpha endpoints (A±0.5) clipped to0..255 and **only** floor/nearest-even/ceil integer premultiplied (p) from (C*a), followed by half-up un-premultiply at these same physical alpha endpoints (and a denominator (a) only when (a>0)); min/max across all 2×3 preselected hypotheses. Apply the **same fixed ±2 output RGB byte envelope** as S3v2k; this is an uncertainty bound, not allowable owner damage. If the possible alpha interval touches0, mark UNKNOWN_LOW_ALPHA (0..255) rather than a confident RGB. Report output interval width per pixel. This is **not** free choice of any arbitrary p or a lookup table trained from the source.
- **F3 opaque source control:** for native alpha255, original isolated RGB should match declared original source owner in full native PNG. Any mismatch is source-provenance FAIL and must be archived.
