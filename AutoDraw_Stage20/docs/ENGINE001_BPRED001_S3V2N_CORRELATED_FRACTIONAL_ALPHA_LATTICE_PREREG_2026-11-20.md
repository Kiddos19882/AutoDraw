## H0, H1 and H2 fixed formula — true correlated alpha

For isolated exported original PNG alpha byte `A∈1..254`, frozen true source RGB channel `C∈0..255`, assume **only for research** that latent physical alpha byte unit `a∈[A-0.5,A+0.5]`. Source premultiplied byte `p` may be `floor(C*a/255)`, `round_to_even(C*a/255)`, or `ceil(C*a/255)`; corresponding exported straight channel is `R=clip(floor(255*p/a+0.5),0,255)`. This candidate is a bound conditional on the assumed family, not a proven Firefox native `toDataURL()` implementation.

**H0**: replay unchanged S3v2m G1 (independent `p_min/a_max`, `p_max/a_min`, fixed padding±2 RGB), verify original 0 misses, 6360/7753 informative, all327 old recovered. No acceptance restatement.

**H1 correlated lattice**: do *not* combine numerator and denominator from incompatible alpha values. For each RGB channel C>0, enumerate all integer p from `floor(C*(A-0.5)/255)` to `ceil(C*(A+0.5)/255)`, clipped to0..255. A given integer p is possible for at least one of the 3 original rounding modes **only within a subset of the alpha range**. A conservative closed superset is `a_p_low=max(A-0.5,255*(p-1)/C)`, `a_p_high=min(A+0.5,255*(p+1)/C)`; discard p if `a_p_low>a_p_high`. For C=0, only p=0 and readback R=0. The superset deliberately includes boundary cases that a specific integer mode may exclude, to prevent false coverage. For each p, readback is nonincreasing in a>0: compute `r_low(p)=clip(floor(255*p/a_p_high+0.5),0,255)`, `r_high(p)=clip(floor(255*p/a_p_low+0.5),0,255)`. Take minimum/maximum over all p for the **same channel** and apply **exactly** the pre-existing ±2 RGB *uncertainty padding* and clip 0..255. This ±2 is NOT a quality tolerance for actual owner damage. Do not choose a p or fractional alpha that best fits observed RGB. Alpha0 remains UNKNOWN; alpha255 remains exact source RGB separately.

This overapproximates the union of floor/nearest-even/ceil for any physical a in the frozen interval but explicitly restricts each candidate p to an alpha subinterval where it can occur. Formula and integer tie handling fixed **before real data**; optional standalone math proof is E1 and not evidence of game fidelity.

**H2 abstention**: only pixels A16..254 whose all 3 correlated RGB intervals have width≤16 bytes count as `INFORMATIVE_INTERVAL`; all A≤15 or any wider interval become `UNKNOWN_LOW_ALPHA` or `UNKNOWN_WIDE_INTERVAL`. Never label them safe to paint across an existing owner; protected-owner foreign modification threshold remains zero.
