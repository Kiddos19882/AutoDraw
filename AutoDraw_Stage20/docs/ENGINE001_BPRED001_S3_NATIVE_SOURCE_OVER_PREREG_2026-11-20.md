## 3. Frozen predictions, metrics, gates

**Frozen C0/source-over reference calculation before ANY S3 experiment:** all source PNG pixels treated as straight RGBA samples in sRGB encoding (do not linearize). Normalize 8-bit alpha as `a=alpha/255`; for top source `T` over bottom `B`, `a_out=a_T+(1-a_T)*a_B`; for each RGB channel `c_out=(c_T*a_T+c_B*a_B*(1-a_T))/a_out` when `a_out>0`, else `c_out=0`. Quantize alpha and each channel with `np.rint(np.clip(value,0,255))` to uint8 **only once at the final output**; use double precision intermediates. For `A_THEN_B` top=B, for `B_THEN_A` top=A, transparent initial background zeros. Never use Canvas readback to fit this formula posthoc. A genuine Egret premultiplied-alpha or gamma discrepancy becomes H1 FAIL and future investigation, not automatic formula change.

- **C0 native-source oracle (for measuring compositing only):** for each width/relation, extract **actual native isolated** A/B RGBA from real E3 PNG. Apply fixed deterministic sRGB RGBA `source-over` (straight vs premultiplied interpretation recorded), quantize exactly once according to prereg algorithm version, compare both ordered composites native Egret AB and BA. No Oracle inference from final AB pixels. This is a calibration diagnostic, not a deployable predictor (isolated native inputs known only in research).
- **C1 research predicted compositor:** use original M2 `area8` (M2 alpha 0..255) for A and B, source-faithful width1/3 geometric shift and source owner RGB A/B, same ordered source-over equation; no new fitted alpha correction or posthoc threshold switch. Treat any mismatched/protected or `UNKNOWN` region as **unknown** for executability; no safe acceptance. Native E3 must be used as ground truth.
- **H1 oracle fidelity:** `C0` RGBA per-channel absolute error **max≤2/255** and mean error **≤1/255** over union of nonzero alpha pixels of each of 40 AB/BA variants (both orderings); otherwise scientific H1 FAIL, preserve channel error map. A transparent pixel with RGB display difference but alpha0 is excluded from this color-error union; report it separately.
- **H2 order sensitivity:** for every width×relation (20 independent pairs), native AB vs BA must differ in RGB on ≥1 physical pixel with actual alpha≥24 both composites; zero overlap/order effect is **FAIL or BLOCKED** only after documented source-validity review, not retune shape/offset after evidence.
- **H3 true-owner consequences (diagnostic, not safety-pass shortcut):** for C1 compute confusion counts per A/B region, protected/foreign pixel changes, source-over RGB/alpha MAE and false-safe in original native composite; any owner-damage false-safe means model is `MODEL_ONLY_UNSAFE`; `UNKNOWN` is not confident-negative. No fabricated source E/F protected map in synthetic scenes, so this H3 **cannot satisfy full-image safety**.
- **E3 technical gate:** original pinned browser+renderer, 80 primary real Egret RGBA PNG, 10 exact repeats,1 blank=91, source/runtime plan SHA per scene, source palette proof, complete native scene logs, per-member SHA, fixed order/width, no missing/selected cases; CI archive. If image source/provider fails, `BLOCKED`, not PASS by synthetic Pillow alone. Predicted overlays are diagnostic images only; must not replace native oracle. No explicit new CHALK claims.
