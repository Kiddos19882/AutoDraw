## Motivation and ground-truth discipline

Первичный original RGB — действительно независимый источник *факта о разнице соседних исходных цветов*; **не является** независимо размеченной человеческой семантикой (глаза, лицо, волосы) или выбранной владельческой game128-картой. Нельзя получить объективную владельческую ground truth из того же nearest palette, SLIC или SAM2/OneFormer предсказания и оценить их ими же. Прямой поиск по (п) `data/`, (п) `testImages/`, (п) `tests/`, (п) `docs/` показал существование старых аннотаторов и Egret-specific ROI, но **не обнаружил подтверждённых независимых pixel-level semantic labels для всех 14 opaque DEV**. Это предварительная инвентаризация, не доказательство отсутствия любой скрытой разметки. Публичная [BSDS500](https://www2.eecs.berkeley.edu/Research/Projects/CS/vision/bsds/) имеет независимые человеческие границы, но её изображения **не являются точными исходниками AutoDraw DEV**; рассматривать как возможный отдельный external benchmark, без подмены настоящих DEV labels.

**CR1 только честная исходная контрастная reference и подготовка review-only evidence:** не включать ambiguous `critical_semantic_recall` в PASS и не использовать прокси `RGB contrast` для утверждения, что все глаза/вся одежда сохранены. Создать пакет для последующей независимой валидации (оригинал, предупреждения, пропуски, review metadata без ручных output masks); **не** предъявлять пакет как уже заполненную аннотацию.

## Exact pre-fixed, deliberately simple independent reference

For RGBA uint8 original source, original opaque-opaque **four-neighbor** pairs only, `contrast_pair = max_c(abs(int(RGB_a[c])-int(RGB_b[c]))) >= 32` (exact integer arithmetic, no scikit Lab, no Sobel, no original predicted source/owner/SLIC labels, no neural masks). Mark **both endpoints** of every qualifying horizontal/vertical pair: `reference_endpoints`. For fully opaque14 all pairs eligible. No diagonals, no resize, no anti-alias correction, no extra dilation; threshold32 is an uncalibrated **fixed diagnostic** and must not be changed after the first DEV measurement to manufacture PASS. Count `reference_endpoints`, `protected_hits`, `unprotected_endpoints`, `core_overlap`, `unknown_overlap`, fraction unprotected. A zero-denominator image is `NOT_APPLICABLE`, not PASS. `SOURCE_CONTRAST_DIAGNOSTIC_FAIL` if any endpoint unprotected, otherwise `PASS_RAW_CONTRAST_REFERENCE_ONLY`. A miss is a source-level geometric discrepancy/false-safe *risk proxy*, **NOT real game owner false-safe**. The `geometric_potential_core` is already `UNKNOWN` and never `ADMISSIBLE`; show its overlap with reference but never interpret `core!=protected` as authorizing game strokes. The previous `Sobel90|ΔE00>=12` production-independent reference maps are the tested baseline, not the independent scorer's inputs.

**Comparisons**: baseline protected vs raw contrast; existing original P2 source-region potential core vs raw contrast; counts per-image and aggregate macro/micro, never aggregate N/A as PASS. Preserve negative results and show example file hashes and source comparison PNGs; *no automatic mask fix in this first CR1*, no thresholds/owner/quality gates changed. Fully opaque source absence of alpha evidence means color contrast is a weaker proxy, not an alternate verified semantic source.
