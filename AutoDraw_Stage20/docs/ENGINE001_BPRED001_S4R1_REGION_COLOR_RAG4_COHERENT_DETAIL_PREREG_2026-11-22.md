## Гипотеза и причинная граница

RAG3 отделил connected main surface geometry (497/1791 на двух сложных DEV) от detail ID, но окрашивание одним source-median swatch на поверхность с небольшой частью контрастных override зон даёт MAE +117.85% на wV6 и не сохраняет тонкие исходные внутренние оттенки; нельзя чинить это подбором старых RAG3 порогов. **H-RAG4:** отдельно связные оригинальные основные поверхности + *вложенные пространственно связные области цвета*, для которых игра выбирает swatch на уровне **целой подобласти**, удержат исходный цвет и реальные тонкие детали без самостоятельного main-surface ID на каждый пиксель. Влияние палитровой пиксельной квантовки не должно создавать геометрическое разделение main surface. Количество внутренних color subregion IDs оценивается отдельно: малый счётчик main не скрывает массовое количество островков на цветовой карте.

## Один кандидат RAG4 — фиксированные функции и числа

1. **Main surface:** fresh masked original-only SLIC (`target_area=128; max_segments=2048; compactness=6; sigma=0`) → 4-connected labels → real opaque 4-neighbor adjacency. Один детерминированный weak-edge RAG sweep из stateless source RAG3 helpers: source mean boundary Lab <=12, boundary strong fraction <=0.125, соседние merged source Lab means <=12; tie-break ascending boundary contrast, descending length, ascending source IDs. Как в фиксированном source helper RAG3, один подтверждённый split сильной непрерывной внутренней original границы (`min_area=32, min_area_fraction=0.20, min_edge_count=8, min_edge_strong_fraction=0.5`), но **без** старого RAG3 color pass. Main IDs всегда 4-connected.
2. **Color proposals, не geometry:** fresh per-pixel nearest-game128 from **current original Lab** допускается *исключительно* как начальная гипотеза выбора swatch и независимый quality baseline, не как main surface ID и не как финальный автоматический owner. Формировать 4-connected вложенные color segments по паре `(main_surface_id, provisional_game_index)`, а не отдельные main surfaces. Каждому связному цветовому сегменту присвоить исходные размеры, source mean Lab, original boundary adjacency и initial regional game swatch. Это source-bounded spatial group, не post-hoc PNG repair.
3. **Одна совместная цветовая согласовка:** среди **целых** color segments только площадь <=3 px делает сегмент *кандидатом* на объединение по цвету с **реально соседним сегментом того же main surface**. Не удалять автоматически все мелкие области. Смена целого сегмента допускается только если max original Lab contrast на общей 4-neighbor границе <=12, разница source mean Lab <=12, и mean RGB MAE исходных пикселей этого сегмента при новом game128 swatch возрастает не более чем на `1.0` (RGB 0..255). Никогда не пересекать strong original-source границу или alpha. Один детерминированный sweep без повторения: choose min(rank=(rounded added RGB MAE, -common boundary length, target swatch index, neighbor ID)). Перекрасить *весь* segment, а не один ошибочный пиксель. Same-swatch соседствует — отдельная topology, никакой forced merge main surfaces.
4. **Hierarchical contract:** после sweep из `(surface, game128 color)` заново 4-connected определить color segments; main `surface_id` неизменен. Для каждого main выбрать `surface_color_index` как наиболее частый текущий swatch с stable tie-break по swatch ID; остальные connected color segments становятся `detail_id` (отдельно 4-connected), `detail_parent_surface_id`, `detail_color_index`. `source_edge` from this original, `unknown/alpha`, `adjacency` 4-neighbor, actual per-pixel composed game128 preview, raw per-image source checksum, geometry and swatch provenance. Unknown color safety не считается SAFE или разрешением executor. Не утверждать semantic classes.
5. **Boundaries:** source strong RGB/Lab edge and alpha survive in separate layer. Main and detail connectivity independently verified. Истинное сохранение внутренних тонких деталей — обязательный synthetic check; слепая nearest128 без spatial source coalescing **не проходит** contract. Нет повторных "repair" или quality-target-adaptive настроек после измерений.
