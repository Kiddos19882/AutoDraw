## Архитектурная гипотеза

RAG4 раскладывает первичное `nearest128` по `(surface, palette_index)` и очищает лишь малые связные компоненты. Это сохраняет цвета, но автоматически создаёт 10 566 и 77 365 *цветовых* регионов на двух сложных DEV. **H-RAG5:** выводить связные существенные цветовые patches по *source RGB/Lab topology* в **двух независимых пространственных масштабах** (основная surface и fine SLIC), назначать **один game128 swatch целому исходному patch**, а очень тонкие контрастные исходные детали сохранять отдельно как source-supported connected overlay, не порождая для основной области palette-pixel islands. Разделять `surface_id`/ `patch_id` / `detail_id` / `color_index` и проверять конечную *paintable* фрагментацию, а не лишь минимальное количество больших ID. Это не RAG4 пороговый sweep, не RAG3 one-swatch surface, не постобработка FC1 PNG.

## Один фиксированный RAG5 candidate (все параметры до исполнения)

1. **Main geometry (coarse scale)** — fresh original-only SLIC `target_area=128, max_segments=2048, compactness=6.0, sigma=0, masked opaque`; 4-connect split. Один детерминированный пространственный RAG merge по исходному Lab: mean boundary delta <=12, доля контраста >=12 на границе <=0.125, разность source mean Lab <=12; затем единственный `confirmed strong boundary split` из source-only helpers (`min_area=32, fraction=0.20, min_edge_count=8, strong_edge_fraction=0.50`). **Не** пользоваться полученными в прошлом RAG3/RAG4 surface IDs, только original и код чистого helper. `surface_id` 4-connected.
2. **Paintable color patches (fine scale)** — второй независимо вычисленный `segmentation.slic` с **`target_area=24, max_segments=12000, compactness=4.0, sigma=0`**, masked opaque, source RGB normalized. Для вырожденных single-row или непрозрачных <16 пикселей — 4-connected alpha regions. Пересекать fresh fine SLIC с fresh main surface и 4-connect split. Реальный source-only 4-neighbor RAG внутри одной основной surface, **один** deterministic merge: border source Lab mean <=**12**, strong fraction <=**0.125**, combined source Lab mean difference <=**12**, sorting (mean-boundary, -shared-length, source patch IDs); ни при каких условиях не склеивать через main/alpha или strong source edge. Новые patch IDs только по source spatial geometry, **никогда не квантованием nearest128**.
3. **Regional swatch:** для каждого нового patch вычислить source-RGB median, не усреднять через main edge; source-Lab medoid/median для 5 nearest Lab palette swatches, добавить один nearest RGB-L1 swatch по median; среди **этого фиксированного набора** выбрать минимальный aggregate source RGB L1 error для всего patch, deterministic tie-break по swatch index. Один game128 цвет для всех пикселей patch; 128 разрешённых цветов, без отдельной limit32. Два соседних patches могут иметь одинаковый swatch, но source patch геометрия остаётся раздельной. Нет background per-pixel palette fallback.
4. **Сильные тонкие детали:** на полном source-resolution независимо вычислить `source_edge` и Lab. Candidate detail pixels = opaque & source strong-edge & local source Lab deviation from assigned patch source-Lab mean >=**20** (Lab Euclidean), additionally original contrast to patch base >=**20**. Связать **только реальные 4-neighbors** candidate pixels **в пределах одного main surface**, если их исходный adjacent Lab delta <=**12** (deterministic union-find, no palette as clustering seed). Каждую связанную group красить единым candidate game128 swatch, выбранным из того же fixed 5 Lab + nearest RGB-L1 set по median actual group RGB. Допустить whole-group overlay только при изменении базового swatch и улучшении aggregate source RGB L1 MAE >=**2.0**; strong single-point source details допускаются, но помечены `semantic_confidence=UNKNOWN`. Этот слой не пересоздаёт main/paintable patch geometry. Если original thin line already correctly represented patch swatch, overlay не нужен. Конечная composed game128 map создаётся **только** из актуальных source patches и допускаемых source-supported overlays; source pixel nearest128 никогда не записывается туда напрямую.
5. **Контракт:** `surface_id`, `patch_id` (4-connected, patch_parent_surface_id), `patch_color_index`, `detail_id` (4-connected, detail_parent_surface_id, detail_color_index), full `source_edge`, `unknown/alpha`, `source_to_logical` image-only coordinates, original+palette+E0 SHA, current composed `game_index`/RGBA preview and real 4-neighbor adjacency. Semantic detail remains UNKNOWN; no executor/production stroke admission without independent validation. Детерминизм double-run raw arrays and SHA; input RGBA never mutated.
