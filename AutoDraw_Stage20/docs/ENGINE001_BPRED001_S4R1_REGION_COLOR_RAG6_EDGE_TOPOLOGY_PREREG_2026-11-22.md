## Hypothesis / original edge topology before palette

RAG5 employed fine SLIC source patches and only then assigned one game128 swatch; source strong-edge map existed separately but game128 reconstruction erased almost 30% strong original-neighbor contrast. New **RAG6** begins *before game palette assignment* with an **original RGB neighbor-weighted graph segmentation** (Felzenszwalb-Huttenlocher) and additional strict source-edge protection. Its connected source-color regions emerge from dissimilarity across true original pixel neighbors, not from nearest128 palette islands, so contrasting original colors are less likely to merge before choosing swatches. The original thin structural line/dot requires independent original-line detail topology, and must be visibly present after regional coloring. Main region geometry, color-region source topology and detail IDs remain separate. Related method ideas: edge-aware superpixels and contour-constrained region graphs, not assumed validations; [Contour-Constrained Superpixels (CVPR 2017)](https://openaccess.thecvf.com/content_cvpr_2017/papers/Lee_Contour-Constrained_Superpixels_for_CVPR_2017_paper.pdf), [Canny SLIC (2018)](https://doi.org/10.1109/Cybermatics_2018.2018.00288).

## Single frozen algorithm RAG6

1. **Coarse main:** recompute identical source-only basic SLIC `target_area=128, max_segments=2048, compactness=6, sigma=0` and source-neighbor RAG weak merge (source Lab mean edge <=12, original strong >=12 fraction <=0.125, union source mean Lab <=12); source-boundary-confirmed split `min_area=32, fraction=0.20, edge_count=8, strong_fraction=0.5`. Each resulting `surface_id` 4-connected. Source image alpha mask must never be crossed. This is a read-only *function reuse*, **not** any past RAG3/RAG5 surface array.
2. **First original-only fine graph topology:** run `skimage.segmentation.felzenszwalb` directly on current original source RGB normalized [0..1] with **scale=70, sigma=0, min_size=4, channel_axis=-1**. This weighted-neighbor algorithm creates original-edge-aware regions before ANY game128 nearest classification. Clip these labels by `(alpha opaque, coarse main surface)`, 4-connected split, assign deterministic IDs; number and source strong-edge leakage are logged. Unlike RAG5 fine SLIC no grid-island/cell as final color region. No per-image seeds or special cases except degenerate single row/column, for which original 4-connected source alpha groups are used.
3. **Topology merge only from ORIGINAL:** within same coarse surface, make source RAG from true 4-neighbor RGB Lab differences. **One deterministic weak-neighbor union**, source Lab boundary mean <=**10.0**, fraction of original strong-Lab>=12 boundary pixels <=**0.10**, weighted merged source region mean Lab difference <=**10.0**. Reject any union crossing real original strong-edge evidence. Tie order (boundary_mean, descending boundary_length, ascending source IDs); no joins based on candidate game128 color equality. Connected split output `patch_id`; source mean and original connectivity remain inspectable.
4. **Region game color:** original RGB median of **whole resulting source-connected patch**, plus 5 nearest genuine game128 palette candidates by Lab of that median and one by RGB-L1 of that median. Choose game128 swatch with minimum **aggregate original RGB L1** across all patch pixels (stable palette index tie-break), **one swatch per coherent patch**, no per-pixel palette fallback. Two separated true source regions may have same color without merging geometry.
5. **Precomputed original-source thin-feature topology:** derive `source strong_edge` from original RGB Lab adjacent pairs >=**12** plus existing stateless source edge function, independently of game128. Candidate pixel = original-source strong_edge AND original Lab-distance from *source region median Lab* >=**12** AND from its immediate original neighborhood (4-neighbor mean Lab, restricted to opaque+same main region) >=**12**. All conditions original-based and computed **before** selecting game swatches, no retained/failed game-edge pixel used as selection. Group candidate pixels with true 4-neighbor source Lab similarity <=**12** without crossing main surface/alpha. Every connected source-line/detail group receives one palette swatch via same original-RGB aggregate L1 candidate method. Overlay entire group only if it changes the underlying regional swatch and reduces aggregate RGB MAE by >=**1.0** per channel; this protects one-pixel high-contrast dots, lines and independent small source shapes. Record source `edge_topology` and `edge_component_id` regardless of overlay admission. Do not infer that every texture edge is meaningful; semantic importance UNKNOWN. Do not create detail region on a weak 1px palette-quantization speckle.
6. **Output:** full original source provenance, `surface_id`, `edge_component_id`, `patch_id`, `patch_parent_surface_id`, `patch_color_index`, `detail_id`, `detail_parent_surface_id`, `detail_color_index`, source strong-edge, composed actual `game_index` and palette preview, actual `paintable_id` by 4-connected `(main, game swatch)` (count *all* components), original alpha/unknown, 4-neighbor main adjacency, source pixel frame/explicit image-to-logical non-calibrated binding. No executor admission (UNKNOWN unsafe): `stroke_admission=FORBIDDEN_UNKNOWN_SOURCE_AND_NATIVE`. Double-build byte-identical and manifests with original/E0/engine SHA, full PNG atlas/NPZ/raw SHA.
