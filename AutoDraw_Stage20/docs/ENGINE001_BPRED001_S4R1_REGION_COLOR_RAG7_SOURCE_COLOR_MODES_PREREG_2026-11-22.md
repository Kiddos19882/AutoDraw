## Why a new architecture

[RAG6 signed source E2](ENGINE001_BPRED001_S4R1_REGION_COLOR_RAG6_E2_RESULTS_2026-11-22.md) had original strong-edge contrast **PASS both complex** (wV82.756%, EZAL76.264%), effective 4-connected paintable regions **PASS** (wV4767, EZAL25097) and numeric 3/4 PASS, but **wV source RGB MAE 6.053 vs fresh game128-nearest 4.876** (>115% extra frozen tolerance, research FAIL). Visual hair deep warm brown/purple changed to nearly neutral black. Hypothesis **H-RAG7:** when an original-edge-constrained spatial patch contains **two significant, spatially coherent original Lab color modes** separated by a real original boundary, one patch-wide palette swatch erases its secondary hue. A bounded **source-only two-mode topology split**, plus best whole-region game128 fitting, should recover important shades while keeping original source edge topology and compact connected paintable regions. This is not a repeat sweep of RAG6 graph scale70 or a post-process final game128 PNG; graph region topology is computed fresh and *new original-mode evidence* determines a distinct additional partition.

Related scientific ideas are source histogram/mode segmentation with spatial region growing and contour-aware palettes ([source-color histogram + region merging](https://www.csd.uoc.gr/~tziritas/papers/color_srg.pdf), [contour-constrained superpixels](https://openaccess.thecvf.com/content_cvpr_2017/papers/Lee_Contour-Constrained_Superpixels_for_CVPR_2017_paper.pdf)). No external paper is proof that RAG7 passes.

## Frozen RAG7 candidate (one fixed specification)

1. **Coarse main & source edge topology**: original-only RAG6 pure helpers, using current original SLIC `target_area=128, max_segments=2048, compactness=6, sigma0`, weak-neighbor source RAG (source boundary Lab mean <=12, strong>=12 fraction <=0.125, union mean Lab <=12) and confirmed original-boundary split (area32, main-fraction0.20, supported edge8, strong fraction0.5), then source Felzenszwalb graph `scale=70, sigma=0, min_size=4`, intersection by current main and current alpha, original RAG single weak union `mean edge<=10, strong fraction<=0.10, region mean<=10`. Source 4-connected `source_patch_id` and `surface_id`; NO palette index is used in any source graph or mode seed.
2. **Original color-mode test inside each source patch**: only patches with **area>=32 opaque pixels**; get *actual original Lab* of these pixels. Compute deterministic principal color direction as leading eigenvector of Lab covariance (`numpy.linalg.eigh` symmetric), orient its largest-magnitude component nonnegative with fixed tie order (L,a,b). Seed two original Lab centers by medians of pixels at projection <=25th and >=75th percentile (inclusive); alternate nearest Lab-center assignment and arithmetic mean center update **exactly 4 times** (tie chooses first). Neither game swatches nor RAG6 artifact influence this topology. Require source center Lab distance **>=16** and smaller mode membership **>=20%** of current patch. If these source-only requirements fail, no split.
3. **Source-connected secondary chromatic mode**: within each original source patch, identify the **minority** Lab mode by sample area (tie chooses mode1) and its true 4-neighbor connected components. Only its **largest** component may split, with connected area **>=12**, also >=**15%** of patch area. Must have a *real original source Lab* 4-neighbor interface with the remainder within that patch of >=**8 neighboring-pixel pairs**, boundary mean Lab difference **>=8**, and fraction with original Lab difference>=**12** at least **0.20**. A floating Lab mode not spatially supported is NOT a paintable geometry seed. No second split per original source patch. Remaining current original pixels retain their primary source region; assign final 4-connected IDs separately so any topological split is explicit and accountable. Never split or join across a main surface/alpha. Save source 2-mode diagnostics, accepted area/ids, and rejected candidate reasons; no post-hoc repair.
4. **Regional game128 selection, distinct from RAG6 restricted median palette:** for each resulting original-connected paintable color patch, compute the **actual aggregate RGB L1 error for all 128 real game swatches** over current source RGB pixels (memory chunk <=4096 pixels; deterministic exact sums), choose minimum full-region source RGB L1 and stable lowest swatch index tie break. For source-mode splits, accept a proposed whole connected secondary patch **only if** the pair of source-region 128-swatch fits reduces original RGB MAE by **>=1.0 per channel** vs current unsplit source region's best all-128 source swatch; otherwise leave original single source patch. No game-nearest pixel seed, no per-pixel color reassignment, no baseline→candidate hard-coding.
5. **Protected thin details**: recompute RAG6-style *original-source* strong edges (Lab neighbor delta>=12), local 4-neighbor original Lab contrast and source color-region median deviation; group candidate source pixels within same current main, with true 4-neighbor original Lab<=12; each source-connected group gets full-128 optimal game swatch. Overlay only when aggregate original RGB MAE drops >=**1.0** per channel and base swatch changes. Do not silently convert main region or color mode into a contour. This thin source detail layer must never be seeded from resulting game swatch differences; it can use its own source-color patch medians only.
6. **Complete outputs**: original SHA/EXIF/alpha and exact palette/E0 SHA, `surface_id` + source main adjacency; `source_patch_id`; new `patch_id` with `patch_parent_surface_id` and `patch_color_index`, `source_mode_id` for accepted secondary source color components, `edge_component_id`, `detail_id` with parents and palette; current `game_index`, `paintable_id` = actual 4-connected (main, composed swatch), fresh nearest128 baseline **for metric only**, source strong-edge, source-to-logical image-only frame, `unknown` and `stroke_admission=FORBIDDEN_UNKNOWN_SOURCE_AND_NATIVE`.
