## Exactly one frozen architecture

1. **Original hard-boundary graph before game colors.** For every opaque horizontal/vertical original pixel-neighbor pair calculate Euclidean CIE76 Lab difference D and original chroma-plane difference C. A forbidden crossing is (a) D>=24, or (b) D>=12 with at least one of its immediately parallel adjacent neighbor pairs also D>=12, or (c) C>=9 with at least one immediately parallel adjacent pair also C>=9. Distinct image alpha ownership is always impassable. Single-pixel high-contrast dots/lines remain protected by clause (a); a lone weak noisy pixel does not become a color region solely because it has a different nearest palette swatch. Store separate horizontal/vertical boolean arrays and raw source contrast values, including forbidden-crossing counts.
2. **Original-only spatial atoms.** Fresh original-only SLIC-based main surfaces (target area128, max_segments2048, compactness6, sigma0) and existing source-only weak-neighbor/main-edge segmentation are recomputed from *this* original. Intersect each source main/SLIC atom with true 4-connected components of allowed pixel graph edges, without traversing a forbidden crossing; do not assume classical ndimage.label can check prohibited internal edges. Each atom is 4-connected via allowed edges, alpha/main isolated. If a candidate split gives zero opaque owner or violates parent/edge constraints, fail closed. Preserve source-protected 1px high-contrast lines/dots as atoms, not a palette-derived outline.
3. **Chromatic seeds and geodesic propagation.** Build per-atom source-only Lab chroma-mode bins with floor(L/10), floor((a+128)/6), floor((b+128)/6); each atom gets the modal original bin (ties lowest bin key). Within each source-main, select all chroma-mode bins represented by >=8 original pixels AND >=2% of that main's opaque pixels as supported geodesic anchors; always retain the most populated mode. Strong-edge isolated 1px original details are separately retained as protected anchors, without a minimum size. Construct true atom adjacency from *allowed* original 4-neighbor crossings and record mean original Lab, chroma contrast and border length. Simultaneous deterministic multi-source Dijkstra assigns weakly attached atoms to anchored source modes, using nonnegative edge cost 1 + 2*C + 0.5*abs(delta L) based only on original Lab atom medians; a forbidden crossing cannot be traversed. Tie-break by anchor (main ID, mode key, first atom ID). A mode never propagates across main/alpha; unanchored disconnected source components retain their own modal source seed. Re-split propagated mode ID by actual allowed 4-connectivity to produce final paint region IDs, and preserve original source boundary/dark-hue provenance. No game palette appears in this step.
4. **Regional palette with explicit contrast interaction, no source-geometry repair.** After source region IDs are frozen, compute exact all128 sums of original-RGB L1 for each region. Start with lowest-index minimizing swatch, then perform **two** deterministic region-ID-ordered ICM passes over each region's top **four** smallest original-RGB L1 palette candidates. Color assignment objective per region = exact original-RGB L1 + 16 times number of true original strongly contrasting (D>=12) touching source-neighbor pixels whose chosen game128 Lab difference would be <12. Other assigned neighbor swatches are fixed for the current update, ties resolve first by RGB L1 then palette index. Count unresolved original strong boundaries; DO NOT create/remove/merge source region IDs in response to palette choices or force a fabricated contrast by editing the original.
5. **Actual output and failure boundaries.** Every region, its parent source main, source-mode seed, source-original strong-boundary edges, palette index, true connected (main,swatch) paintable ID, original-neighbor adjacency, original alpha/UNKNOWN, preview RGBA and logical projection marked uncalibrated are versioned.
