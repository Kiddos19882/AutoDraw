## Why a new architecture, not patching S5-R1

S5-R1 is deterministic and negative guards function, but fixed **2000 candidate trials** exhaust at the beginning of a raster: only12–13 strokes per image; wV2.4609%, Hello Kitty0.0901%, EZAL0.0690%, Pink Kitty0.5334% potential modeled coverage, **all PARTIAL**. Four source original SHA and full arrays independently checked, native owner/calibration unknown. A single ideal width10 capsule evaluated on512² diagonal ~1.73–1.78s Python, so unrestricted per-pixel and per-angle search on multi-megapixel originals is computationally unsuitable. Neither 100% rectangle comparator nor E2 ideal envelope means native Egret quality.

## One candidate S5-R2, no parallel planner implementations

**Region-first shape/fairness strategy** rather than first-uncovered-row greedy:
1. Input: fresh original bytes→ existing CTR1→ **verified S4.6** quarantine source arrays (`original_rgba`, `game_index`, `paintable_id`, `protected_original_dot`, `source_edge`). Never old artistic maps or scene-specific ROI. Validate SHA, engine128 blob, array shapes/dtypes, 0..127 swatches and alpha; if missing or tampered fail closed. Reuse S5-R1's `build_from_verified_s46` pattern, not import its candidate selection; retain historical S5-R1 verbatim for comparable baseline.
2. Group by nonzero `paintable_id` with fixed game128 index. Compute per-region area, bbox, centroid/interior location and source-boundary proximity in one or few vectorized passes (use existing NumPy/SciPy already installed). Explicitly flag and prioritize source `protected_original_dot` points; each is constrained to width1 candidate to preserve fragile original details, not altered source. Do not infer semantic eye/face labels from hardcoded ROIs.
3. Produce deterministic **fair round-robin by region**: first candidate per distinct region, ordering critical dots then region area and region id (no permanent initial top-left bias), followed by additional uncovered-region passes. When total regions exceed budget, report excluded/unvisited count and `PARTIAL`; never silently pretend whole-image coverage. Fixed source-pixel budgets **2000 footprint candidate evaluations** and **200 accepted strokes** for initial R1-vs-R2 comparison; source pixel and native sizes remain different. Candidate assignment is independent of source image file name.
4. Each proposed stroke uses one existing `swept_capsule_pixel_masks` **ideal round capsule** with `brush_value` from1..10, source-local width rationale based on regional clearance, normal polyline2 points, short path length0/2/6/12 px, direction from 0,45,90,135 plus region's orientation/tangent if reliably computable; any angle supported via numeric normalized vector, no fixed angle gate. Choose a bounded deterministic subset per region (not an O(number of pixels) width-angle search). Every `potential_cells` must be same `paintable_id`, same game index, and alpha255; otherwise reject or width1. At image edges never claim pixels outside canvas are known safe; leave coordinates source-only.
5. Score proposals by new correct modeled potential coverage plus protected dot preservation and low border risk, then fewer strokes/length/color switches only secondary. Same-color overdraw allowed, but **never** claim native compositing/color preservation from ideal coverage. Track `guaranteed_cells` separately, reject reasons, visited/unvisited region IDs/counts, global uncovered and per-region area, source SHA/provenance. Final status `PARTIAL` if uncovered>0, and all plans/strokes `safe_to_execute=false`, `admissible_for_gameplay=false`, `source_owner_status=MISSING`, `native_calibration=UNVERIFIED`, `drawing_mode=normal`, `smooth=false`.
6. Bounded scheduling fairness/ledger is one research-only component under `tests/`; existing Egret reference renderer/Stage6 executor/Bridge/Monitor, S4.6 frozen source contract and P4D3 artifacts remain untouched. No production or exact CHALK improvements claimed. **If new native calibration/owner evidence absent, no gameplay execution.**
