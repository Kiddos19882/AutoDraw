1. Fresh original bytes→existing CTR1→verified S4.6 immutable `original_rgba`, `paintable_id`, `game_index`, `protected_original_dot`, contour evidence; refuse modified SHA, unknown owner, legacy generated artwork or non-original source. No changes to S4 colors, acceptance, Stage6.
2. For each source region, compute a **distance transform to forbidden cells / source-border** (pixel-cell clearance) and derive feasible interior centerline intervals for widths1..10. Treat erosion/EDT as conservative candidate prefilter, not proof of exact capsule raster or source Egret; never rely on float-aligned safe or stored translated brush masks. Respect source-boundary/alpha and source pixel corners. Use vectorized run-length/row-column/diagonal interval scans and region medial-axis/major-axis proposal only when bounded; avoid all-pixel×all-angle brute force.
3. Prefer **long, source-connected interior lines** on large regions, with adaptive widths and directions from principal/midline geometry; allow cardinal, diagonals, and arbitrary numeric angles when supported. Clip each candidate to the region clearance corridor **before** calling the same existing `swept_capsule_pixel_masks` ideal round-capsule verifier. Orientation independent of original image filename. Evaluate actual model potential source owner/game/alpha for each selected stroke; reject any inappropriate cell, preserve all source contours/protected evidence.
