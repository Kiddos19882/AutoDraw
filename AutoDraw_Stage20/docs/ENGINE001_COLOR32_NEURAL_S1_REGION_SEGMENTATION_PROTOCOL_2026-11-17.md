# ENGINE-001 / COLOR32-NEURAL-S1 — нейросетевая сегментация цветовых областей

**Пререгистрация 2026-11-17 до кода и результатов NEURAL-S1.** Задача `ENGINE-001`, отдельный ID `ENGINE001_COLOR32_NEURAL_S1_REGION_MASKS`; рабочая ветка `feature/image-geometry-optimization`. Это **исследование подготовки цветовой карты**, не новая production-покраска и не замена замороженных P4c0/P4c1/P4c2.

## Наблюдаемая проблема и исходная база

Пользователь визуально отклонил P4c2 paint-only composite как чрезмерно раздробленный разноцветными островками. Оригинальный Windows Egret [CI44119887018](https://github.com/Kiddos19882/AutoDraw/actions/runs/44119887018), SHA `9cd12e2c04d47f7fabf6a3d4bae796a1e1606183`, job `134168079359` завершился SUCCESS **как выполнение**, но в логе реальный outcome `P4C2_NATIVE_PAINT_FAIL`: 14/17 original G32 owners ниже99% native alpha24; общий safety gate alpha24/128 FAIL. Артефакт `14343464778` ZIP digest GitHub `sha256:97a6007b8b88939d0449b5dee2ae5fe24f757db70a4292b8415229914e486e1c`, original `P4c1-PAINT-ONLY-composite.png` — **не финальная раскраска**: 410 оригинальных V44-B контуров не включены. Исходная G32 сегментация из `run_engine001_color32_s2_edge_protection.py` работает через nearest palette32 ΔE00 + `strong_edges` + `protected_merge` (`AREA=8`, `EXTRA=5.0`, `PASSES=2`); это deterministic baseline и не semantic understanding. Две причины негативного изображения — дробная G32 разметка и слабое native покрытие — **не разделены экспериментально**, поэтому не приписывать все видимые дефекты исключительно сегментации.

Общие неизменяемые входы: пользовательское `testImages/wV6VeZI9S1Y.png` SHA-256 `07cc4568cb5e90d9514bc6f6c2112fee623f87f8fd0cea02fa517b04108e502a`, исходная 150×240 ROI, BoardPane 460×240, фиксированная 32-цветная игровая палитра Git blob `461b5f3725b9b79888ad36e807b3cf4c9e445e98`, фон индекс30. Оригинальная frozen G32 исходная PNG SHA-256 `b8dcd5f00d2c39c81997aaae084eaae19a776454e6fd6466209839288c1e5637`; исходный P4c1 ZIP `fac1fcf1ff6a43ac6e59da116b68b86e2238c2da13be0b167cf34f8241ac5eeb`. Контуры AniLines/V44-B 410 цветных LAST/1792 вершин сохраняются неизменными и не используются как якобы полученная новая маска.

## Гипотеза, кандидаты и ограничения модели

H0: новая маска не улучшит одновременно цельность цветовых областей **и** визуальную узнаваемость при тех же 32 цветах. H1: neural region proposals с контурной согласованностью уменьшают паразитные островки в границах без потери важных деталей. Само по себе уменьшение числа областей НЕ доказывает сохранение лица/позы или игровое качество.

- **B0 — frozen G32**: неизменённая исходная маска; эталон для сравнения.
- **N1 — SAM 2.1 hiera tiny auto masks**: настоящие маски из официального [facebookresearch/sam2](https://github.com/facebookresearch/sam2), Python≥3.10/PyTorch≥2.5.1; mask generation via automatic mask generator. В пилоте фиксировать points_per_side=8, points_per_batch=8, crop_n_layers=0, pred_iou_thresh=0.8, stability_score_thresh=0.95, до32 лучших масок после NMS, без скрытых ручных промптов. Inference на том же оригинальном RGB150×240; маски всегда хранятся на исходной ROI и не сливаются по цвету до записи. PyTorch/SAM2/weights SHA, URL, код, среда и runtime обязательно писать в raw report. До первой проверки точного checkpoint/code SHA считать эксперимент **exploratory**, не независимой validation.
- **N2 — contour-aware SAM2 masks**: те же N1 proposals и параметры модели; **единственное последующее преобразование** — защитить границы по уже существующему `strong_edges` (исходные protected edges) без повторного neural inference. Такой proxy НЕ объявлять «нейронной AniLines»; применение настоящей AniLines-маски допустимо только после отдельной hash-привязки к точному оригинальному Egret/AniLines artifact в новом experiment ID.
- **F1 / FlatMagic**: научный подход к flat-color областям ([CHI2022](https://cragl.cs.gmu.edu/flatmagic/), [backend](https://github.com/Nauhcnay/flat_magic_backend)). **Не считать контрольной измеренной нейросетевой моделью**, пока не подтверждены исполняемый checkpoint, license, веса, входная схема и независимое фактическое inference. Если недоступно — `BLOCKED_MODEL`, а не симуляция FlatMagic под видом inference.

## Протокол оценки, заранее фиксированные параметры и запреты

1. Зафиксировать оригинальные source/palette SHA, оригинальную frozen G32 map и модель checkpoint/config/code SHA. Материализовать маски `uint8/boolean 240×150` с уникальными ID, площадью, оригинальными shape; проверка конечности, размеров, ненулевых масок и неизменности исходного PNG; любой подменённый JSON/PNG/модель => `BLOCKED_INPUT`.
2. Из предложений составить **неперекрывающуюся partition**: маски сортировать по убыванию predicted IoU, stability, затем площади и ID; каждый пиксель принадлежит не более одной маске; остальное разбивать на существующие G32 connected components с неизменённым фоном30. Никогда не смешивать разные исходные ROIs, изменять исходный индекс или переносить цвет с чужого объекта по догадке; никакой новой генеративной RGB.
3. Каждой области назначать один из 32 цветов как **medoid ближайший к среднему CIELAB original pixels по ΔE00**. Для защищённых контурных пикселей B0 original G32 label сохранять неизменным; в N2 этот prior фиксирован, в N1 сохранять как отдельную диагностику. Не изменять список32 и не выдавать семантическую категорию («волосы») без модели, которая её действительно предсказывает.
4. Source-only метрики на **всей** ROI150×240: ΔE00 original RGB vs projected palette RGB (mean/p95), RGB MAE, 4/8-connected region counts и singletons per palette owner, доля островков площадью≤4, цветовых переключений соседних пикселей, доля protected-edge G32 labels overwritten, number of used palette colors, foreground/background drift, fragment boundary length. Все измерения source **E2/MODEL_ONLY**, никакого прямоугольного «покрытия кисти».
5. Записать raw original, original frozen G32, предложенные маски, partition, index PNG/N1/N2, RGB renders, difference/edge overlays, SHA-linked JSON, модель/checkpoint SHA, Python/Torch/SAM2 version, GH SHA/run ID, refusals. Каждый запуск — уникальный архив/ID, без перезаписи. Для N1/N2 source успех **только candidate**: уменьшение 4-connected non-background components как минимум на25%, число palette цветов≤32, no change protected edge labels (N2), mean ΔE00 growth≤+1.0 against B0; не использовать это как game-native acceptance. Дополнительно **обязательная визуальная проверка**: узнаваемость лица, волос, одежды/позы по оригиналу и выбранному пользователем V44-B; даже source metric pass без visual gate = `VISUAL_PENDING`, не принять.
6. Не выбирать победителя только по снижению числа островков — чрезмерно сглаженная пустая раскраска должна быть отвергнута по color error/визуалу. Вне этой пререгистрации не подбирать пороги постфактум. Всего одна сложная картинка = exploratory holdout, не E5; для обобщения нужен отдельный набор изображений и versioned validation.
7. Реальная **Egret native** α24 per owner≥99%, max foreign leakage3 logical px, целостность больших форм, original410 V44-B LAST, ≤3000 strokes /5900 vertices и E4/E5/live run-bound exact CHALK остаются **отдельными последующими экспериментами**. Никаких подмен P4c2 source masks/protocol, production/executor/Bridge/Monitor/master.
