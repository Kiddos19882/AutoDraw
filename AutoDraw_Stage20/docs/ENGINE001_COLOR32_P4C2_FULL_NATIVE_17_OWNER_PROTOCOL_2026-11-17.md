## Frozen acceptance/negative-result rules

1. **Input identity and completeness:** source/palette/renderer blob pins and original P4c0/P4c1 path artifact SHA match. Each of 17 isolated native PNGs plus native composite must be nonempty, match expected 1380×720 RGBA and pass linked SHA verification. A missing owner, mismatch, blank control ink, browser/renderer fallback or incomplete job => `BLOCKED` or `FAIL`, never `PASS`.
2. **Brush safety:** for **every owner** zero actual foreign native alpha ink beyond 3 logical px **and** zero ink outside original ROI at alpha24 and128; do not round fractional logical distances down to meet tolerance. Record actual leaks within3px too. Historical P3 width6 leakage is a separate negative experiment, not overwritten.
3. **Native coverage:** alpha24 ≥99% for **each** of all17 original nonwhite G32 owners. Also report alpha128 fractions without moving either alpha threshold. Original 410 V44-B detail strokes LAST and recognizable full portrait are required to claim full-image acceptance; source-only color-map and hybrid overlay cannot substitute.
4. **Resource gate:** 1543 total strokes/5277 synthetic vertices, including exact410 last details, each native paint stroke valid for existing renderer API. These are **NOT exact CHALK**. Any candidate unable to execute under frozen limits => `BLOCKED_RESOURCE`; preserve partial captures, never accept them as final image.
5. **Outcome labels:** `P4C2_NATIVE_FULL_IMAGE_PASS` only if all gates plus original V44-B LAST and visual criteria are verified; `P4C2_NATIVE_PAINT_FAIL` if full native paint is measured but coverage or safety fails; `P4C2_NATIVE_PAINT_ONLY_PARTIAL` if paint-only native metrics exist without verified LAST contour integration; `BLOCKED_*` on missing/corrupt primary evidence. Do not change acceptance thresholds after result. Freeze artifacts/report SHA, include commit/run ID/environment and explicit negative findings.
6. **Game validation:** real live E4/E5 and exact CHALK `post.pointCount-pre.pointCount` need a separate bound game run; native Egret E3 alone cannot establish them. All generated plans `safe_to_execute_game=False`.
