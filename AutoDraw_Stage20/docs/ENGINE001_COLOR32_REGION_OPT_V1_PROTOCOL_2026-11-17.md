## Четыре предзаданных метода

- **A MEDIANCUT8 baseline:** existing source-ROI Pillow `Image.quantize(colors=8, method=MEDIANCUT, dither=NONE)`; canonical stable palette label IDs and quantized RGB. **Только baseline**; не приписывать A ограничение 32 игровых RGB.
- **B GAME32 nearest:** existing `quantize_image_to_palette(roi, game32)` pixel CIEDE2000, no dithering; palette only real game swatches.
- **C GAME32 + SLIC:** `skimage.segmentation.slic` of original RGB /255 (not quantized) with fixed `n_segments=350, compactness=8, sigma=0, start_label=0, convert2lab=True, enforce_connectivity=True`. Each superpixel obtains original mean RGB, selects nearest of32 game swatches by existing CIEDE2000; paint all its pixels one swatch. If SLIC fails/degenerates, fail closed, not silent fallback.
- **D GAME32 + SLIC + edge-guarded region merge:** start with C label map, use **8-connected** same-class components (not arbitrary distant same-color pixels). Up to3 deterministic passes, each pass choose regions whose source pixel area <=16; relabel to an adjacent palette color only when existing game swatch ΔE00 <=12.0 AND source neighboring original RGB boundary color difference 75th percentile <=30.0 (sRGB Euclidean). Protect high-contrast original edges; relabel original connected region only, never new palette RGB. Deterministic tie break: minimal palette ΔE00, then minimal boundary 75th percentile, then largest shared boundary, then lowest neighbor colorIndex. No pass if no eligible region. D may preserve many small regions if all merges unsafe; report rejects and unchanged components, no posthoc cutoff tuning.
