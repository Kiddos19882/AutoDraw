## Hypothesis, controls and outputs

**H1 (E0):** A pretrained OneFormer semantic segmentation of **original RGB**, rather than already lossy G32, can reveal reliable high-level visual region boundaries that later assist (but do not replace) 32-swatch color-owner segmentation. S5-P1 **does not itself output a game32 painted proposal**; if inference does not work or mask has poor/degenerate coverage, reject OneFormer guidance as `BLOCKED_ONEFORMER_SEMANTIC_GUIDE` and leave S4/S3/production unchanged.

- **Input:** exact original PNG, same source-reader RGB resize/ROI `read_source` 150×240 logical; semantic model sees full original image with its own documented preprocessing. Save `original-RGB.png` for comparison. No use of source G32 as input or pseudo-label.
- **Model:** semantic segmentation mode only, output one integer ADE20K class label per pixel, resized to 240×150 via OneFormer processor segmentation postprocessor. No resize of class IDs via bilinear interpolation. Save exact class IDs `oneformer-semantic-labels.png` (8-bit palette only if class_count ≤256), visualization `oneformer-semantic-preview.png` and `oneformer-semantic-boundaries.png`, class histogram and total semantic boundaries. Do not falsely present arbitrary visualization RGB as game32 colors.
- **Provenance:** record exact Git SHA, GitHub run, original-image hash, model revision, download checkpoint SHA256, model classes, output and SHA256 hashes; no artifact overwrites. Preflight fails on missing/incorrect source, missing model or invalid output dimensions/values, and preserves failure reason JSON even if model cannot load.
- **Quantification:** count distinct semantic labels, dominance of largest class, semantic boundary count and image-space connected components. Qualitative inspect face/hair/clothing/outline; OneFormer ADE20K labels are semantic, not expected to match exact game-color islands. Informative gate for further study only: **at least two distinct semantic classes, largest class ≤95% of pixels, all label indices valid and no NaN**. This is a feasibility gate, **not** a source color quality gate or game acceptance.
- **Comparison:** B0 original G32, S3 J0/J1 and S4 D0/D1 remain historical references; no rewriting thresholds or results.
