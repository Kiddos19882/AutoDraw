## 2. Frozen first-candidate numerical parameters (locked before first P1 result)

- ROI: exactly logical H=240 W=150, original RGB uint8 via read_source with pin. Original-only border background: existing white_background original CIELAB-to-palette-white DeltaE00 <=10, 8-connected edge-connected flood. Same fixed background for M0, N1, N2; no neural substitution for original white detail. Historical 3929 B0 background disagreement may persist: report FAIL, do not silently choose another white threshold.
- Source multi-scale partition: fine skimage.segmentation.slic RGB n_segments=1600, compactness=5.0, sigma=0.3, start_label=0, convert2lab=True, enforce_connectivity=True. Coarse independent diagnostic/context SLIC n_segments=320, compactness=8.0, sigma=0.7, other params identical. Use fine labels clipped by nonbackground, split into 4-connected regions; assign contiguous deterministic row-major IDs 0..K-1; background -1. Do not seed from G32 or any neural mask. Coarse labels never permit crossing original strong edges.
- Protected original-detail pixels: existing strong_edges Sobel 90th percentile of positive grayscale gradient. Add mathematical local detail seeds: a source pixel is protected if max original CIELAB DeltaE00 to any of its 4-neighbors >=12 and the 8x8 surrounding patch has median source-to-neighbor DeltaE00 >=8.5. Log two protection maps and original RGB patches; neither can be removed by neural confidence. This heuristic is predeclared, not a semantic detector. No deletion of a small region just for its area.
- Source medoid: for each connected region choose actual original-member RGB minimizing squared Euclidean LAB distance to the region LAB median, ties row-major. No neural invented RGB or background substitution.
- Candidate merge pass: source area 1..64 px, target area >= source area; at least 2 shared four-neighbor contacts. Reject any merge if source region includes a protected pixel or either side of the joining seam is protected; disallow background and nonadjacent merges. Require source-region LAB medians DeltaE00 <=8.0, source mean DeltaE00 after replacing with target original medoid worsens <=2.0, and either both regions lie in the same coarse superpixel or source median-to-median DeltaE00 <=4.0. A source region with no eligible target stays separate. One deterministic pass over original labels in ascending (region area, region ID), skip a proposal when its target has already been absorbed; no chained/hidden retune. Save every merge proposal, rejection reason and actual changed pixel count.
- M0 (control) eligible-target score = source median DeltaE00; ties then descending shared contacts, target region ID.
- N1 (genuine neural assistant) identical partition and hard source guards as M0. Recompute per-R2-region L2 normalized means from archived S4 dense features. For each already eligible adjacent pair compute cosine; **bonus only when cosine >=0.85**: bonus=4.0*min(1, (cosine-0.85)/0.15), score=source median DeltaE00 - bonus. If cosine <0.85 or feature unavailable (but available tensor invalid), N1 uses source score for that pair; invalid tensor or archive => N1 BLOCKED, never synthetic neural features. N1 may reorder eligible target selection only, not create or authorize an inadmissible merge. Report all cosine scores and changed decisions; if N1 matches M0, status NEURAL_NO_EFFECT.
- N2 (optional independent BiRefNet hint) same N1 plus add soft score penalty +2.0*min(1, abs(meanAlphaSource-meanAlphaTarget)/64.0) for every already eligible candidate, using true pinned S5-P2 alpha. This discourages cross-foreground merge but is **not** a hard color or background decision. Missing/invalid alpha marks N2 BLOCKED without invalidating M0/N1.
- RGB preview M0_RGB/N1_RGB/N2_RGB is unrestricted original medoid colors, not game32 or Egret coverage. Game32 projection comes separately, only pinned 32, source LAB/chroma/hue plausibility and explicit unrepresentable abstention; never turn unresolved pixels into a fake valid color. Neural feature N3 game32 tie-break is **out of scope**, needs new P2 protocol.
- Detail crop rectangles in logical (x0,y0,x1,y1), exclusive xmax/ymax: female face/eyes (26,34,85,100), male face/eyes (72,14,123,92), bow/white hair (10,26,70,100), orange/hands (31,125,115,165), blouse/buttons (24,92,105,147), skirt/hem (18,153,118,219). All 36,000 original pixels partitioned exactly once, protected source region ownership unchanged by merging, no background changes, all representative RGB present in source member sets.
