Base = existing B1_CHROMA12_SPATIAL 32-index PNG, NOT re-infer from P0; all base original/protected/palette RGB exact. For each 4-connected equal-swatch region of area at most max_area, **one frozen snapshot pass only**, no resegmenting/repeated iterative pass. Reject if donor touches any protected original pixel, if donor index30 white, or any changed source pixel lacks its original-source-valid destination swatch (Lab chroma(dest) <= Lab chroma(source)+12 and L(dest) <= L(source)+22). Never cross true original source edge or protected source pixel: for seam count only 4-neighbor contacts with original CIEDE2000 <=8 AND both seam endpoints unprotected. Candidate target is adjacent preexisting game32 swatch component with area > max_area (so target never an eligible donor); at least one safe seam contact. Full donor must attach to that target. Prefer target with minimum original CIEDE2000 per-pixel **extra vs the donor's current game swatch**, then larger safe seam contact count, then lower target swatch index; no random ordering. Pixelwise original color cost increase cap as below, and do not alter any B1 initial protected swatch labels. A region with no safe target is KEEP, including diagonal-only source details.
- **B2_SAFE4**: area <=4, mean extra original ΔE00 <=1.5, maximum per-member extra <=6.0, safe contacts>=1, only target area>4.
- **B2_SAFE12**: area <=12, mean extra original ΔE00 <=2.5, maximum per-member extra <=8.0, safe contacts>=1, only target area>12.
At most one assignment per donor, edits applied simultaneously from original labels. No merging to fabricated colors, no adding palette choices. Frozen original protected mask is **not** a guarantee game palette is semantically right on those protected points.
