Both selected endpoints must be the same nonwhite game swatch, belong to **different** 4-connected components of that swatch; the two orthogonally intervening pixels each have different index from the endpoints. Drop any candidate with any of its four 2×2 pixels in original 7947-pixel protected source mask, drop pairs with coordinates outside full 150×240 ROI. Categorize the two intervening pixels: BOTH_FOREIGN (neither white index30), MIXED (one white), BOTH_WHITE (both white); for BOTH_FOREIGN the other pixels may differ from one another. Sort candidates by (top row y, left column x, orientation NW-SE before NE-SW, swatch ascending). Select **at most two per category with distinct swatch indices within that category** (first match by sort order), in fixed order BOTH_FOREIGN, MIXED, BOTH_WHITE; if fewer than two exist report missing cases as `INSUFFICIENT_SOURCE_PAIRS` (do not invent fixtures).
