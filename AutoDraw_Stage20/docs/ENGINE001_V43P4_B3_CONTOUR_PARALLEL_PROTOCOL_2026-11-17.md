## Решение пользователя и главная гипотеза

Пользователь попросил действовать как при закрашивании раскраски: вести кисть *вдоль границы участка*, слегка перекрывать будущую обводку изнутри, продолжать кольцами/витками к центру; подбирать размер кисти по местной ширине. **Временное явное правило:** `overlap_with_own_color_penalty=0` — сколько раз закрашенная область перекрывается кистью ТОГО ЖЕ цвета, сейчас не важно. Не путать с перекрытием чужого цвета: чужие цвета и выход >3 logical px контролируются отдельно. Количество штрихов, вершин и переключений по-прежнему ограничено; это не бесконечная квота.

**Гипотеза E0:** контурно-параллельные широкие полилинии по connected components / interior distance bands могут сохранить целостность окраски и расходовать существенно меньше вершин, чем отдельные micro-strokes B2, без большой зависимости от горизонтальных line sweeps B0. Потребуются настоящие BoardPane/Egret footprint measurement, а не только OpenCV.

## First B3 source method and constraints (locked before result)

1. Use the exact frozen ROI150×240 and owner labels4–7, stable source order and ids `p4-b3-OWNER-NNNNN`. No old paint routes from A/B0/B1/B2; no modifications to original410 RGB V44-B detail, their order LAST. Color RGB pinned from A per-class mode: owner4=15921900,5=14466476,6=11174513,7=5191999.
2. For each owner mask, compute Euclidean interior distance from the source color boundary in logical pixels. Candidate ring centerlines follow **eroded-mask contours** at selected widths 10→6→4→2 (erosion distances = width/2, + optional small contour inset). Contours may include multiple disjoint loops, holes or narrow components. Keep each disconnected contour a separate stroke; never bridge through another owner. Convert closed loops to polylines with a closing endpoint where safe and limit any single path to128 accepted vertices. Treat repeated ink over the same owner as **zero scoring penalty**. Prioritize source coverage and preserve details visually, not stroke-count reduction alone.
3. Distinct geometry options: width10/6/4/2 using actual radii only after Egret. **No more than3 logical px foreign/exterior** allowed; *provisional* source model must fail closed if any modeled footprint extends further than3 logical px from target owner. A B3 candidate can be marked `SOURCE_MODEL_ONLY`, never accepted as native. Short width2 corrections for narrow residuals are permitted only if >0 owner gain and budget remains, but a single-pixel-per-stroke approach exhausting budget must return `BLOCKED_RESOURCE` and report all owner residuals.
4. **Resource scheduling across colors:** avoid per-color starvation seen in B2. At each stage choose among all four owners in a deterministic, fair scheduler using normalized uncovered owner fraction, absolute gain per vertex and stable owner/path tie break. Reserve frozen410 details with1792 synthetic vertices; hard bounds max3000 strokes and5900 total synthetic vertices (=> <=4108 new paint vertices). If one class cannot be represented adequately, return **BLOCKED_RESOURCE/QUALITY_NOT_ESTABLISHED**, not a partial successful painting.
5. For model ranking, same-color overlap is *unconditionally unpenalized* (no revisit count, no additional color-switch penalty at this phase). Foreign overlap is a separate metric (including allowable <=3px); never ignore or reward crossing to other source colors. Capture coverage and leakage for each owner after whole stage, per-owner chosen width histogram, contours/holes/connected components, potential unpainted regions, added points and switches.
6. **Fail-closed source gate:** output JSON with source SHA, deterministic labels SHA, geometry+fixed parameters, raw candidate paths and owner metrics, blocked reason, `safe_to_execute=false`, `game_exact_CHALK=null`. Source-only E2 includes unit tests of holes, disjoint components, closed contours, width shrink, repeatability, fairness, no foreign >3px MODEL_ONLY, budget accounting. Preserve source artifact even on a blocker; do not promote on a passing workflow alone.
