# Обязательная игровая геометрия кисти при тестировании AutoDraw

**Дата:** 2026-11-15. **Статус:** ACTIVE / принятое требование пользователя. **Область:** все новые, возобновляемые и изменяемые тесты, эксперименты, визуальные сравнения и quality/coverage/leakage/CHALK-оценки, где результат зависит от формы, размера, направления или фактического следа кисти. **Задача:** ENGINE-001, продолжение после V30.

## Нормативное правило

**Тест покрытия рисунка должен использовать кисть в форме, размере и с поведением, соответствующими реальной игре.** Абстрактная прямоугольная заливка по AABB, пиксели центров линий, простая геометрическая капсула и Pillow/OpenCV line **не допускаются в качестве единственного доказательства** реального покрытия, отсутствия протекания цвета, качества или стоимости штрихов. В частности, не принимать алгоритм в production на основании прямоугольных модельных «100% coverage».

Проверяемый первичный эталон — архивный код актуального игрового `BoardPane.redraw()` с настоящим Egret `Graphics.lineStyle`, path/cap/join/mask/scale и CanvasRenderer/WebGLRenderer, воспроизведённый существующим `tests/game_renderer_reference.js`, а для конечной интеграции — фактический live-снимок и run-bound данные Game Monitor + Bridge. Архивный Egret сам по себе — E3, **не** live E4. Изменение версии/реализации игры требует нового source binding, проверки и фиксации SHA.

Не предполагать без измерения, что все игровые кисти строго круговые/капсульные в каждом пикселе: растеризация, антиалиасинг, blend, реальные концы и соединения штрихов, scale, клиппинг и смена ширины проверяются нативным эталоном. Параметры `lineStyle(width)`, `brush radius`, `brush value`, CSS/client, logical и PNG backing **разные величины**; сохранять точное преобразование и фактические API-аргументы. Менять ширину внутри одного игрового штриха считать **UNKNOWN** до подтверждения в источнике и runtime.

## Обязательный протокол для новых brush-dependent опытов

1. **Перед измерениями:** зафиксировать SHA игрового Egret bundle и исходного изображения, версию BoardPane, backend (WebGL/Canvas), реальные stroke point coordinates, width/brush settings, cap/join, board mask, coordinate transform, backing resolution, цвета/альфу, source target mask, baseline, sample IDs и acceptance gates. Отдельно фиксировать приоритет узнаваемости: лицо, волосы, поза, цветовая композиция.
2. **Фактический отпечаток:** прогонять согласованный набор ширин и траекторий в настоящем архивном игровом renderer: отдельная точка, короткий прямой, диагональ, поворот/излом, изгиб, узкая цветовая область, граница двух цветов, край доски. Обязателен пустой контроль; сравнение Canvas/WebGL там, где backend доступен. Для размеров кисти, не прошедших native-контроль, результат **NOT_VALIDATED/BLOCKED**, а не подмена прямоугольником.
3. **Анализ native RGBA:** сохранять исходные PNG/пиксели с alpha и геометрией на логической доске. Метрики coverage/leakage/overlap вычислять из фактического native следа кисти и целевой маски/цвета; сохранять разные alpha thresholds как диагностику, не подбирать пороги задним числом. Проверять и объявлять границы допустимых 3 логических px и >=99% quality coverage согласно действующим проектным acceptance gates, но E3 offline не равен E4 live.
4. **Безопасность и ресурс:** никакой predictor, path length, число штрихов или endpoints не заменяют точный игровой CHALK. Exact CHALK только валидный run-bound `post.pointCount - pre.pointCount`; game-native render alone не подтверждает CHALK. Fail-closed если нет валидной калибровки или не пройдены runtime quality gates.
5. **Открытость результатов:** при расхождении ideal capsule / rectangular proxy / actual Egret сохранять ошибку по отдельным случаям, первичные evidence и отрицательные результаты; новые реализации получают отдельный protocol/experiment ID. Не переписывать исторические V23–V30 отчёты: их RECTANGLE_MODEL_ONLY-поля остаются исторически корректно обозначенными, но **не могут использоваться для принятия кисти или coverage**.

## Допустимые исключения без подмены реальной кисти

Unit-тест арифметики, поиска путей, оптимизатора, валидатора JSON, масок и абстрактной геометрии можно выполнять без Egret, если он явно обозначен **E1/E2 MODEL_ONLY**, не делает утверждений об игровом покрытии/утечке/CHALK и не проходит quality gate вместо нативного теста. Для теста без рисования кисти требование нативного рендерера не применимо.

`source/preparation/brush_footprint_geometry.py` реализует математическую капсулу с округлыми окончаниями и маски `potential_cells/guaranteed_cells`: годится для раннего широкого поиска кандидатов, но не для окончательного подтверждения настоящего игрового следа без сравнительного теста Egret. `source/preparation/interior_fill_planner.py` и `outline_first_fill_planner.py` пока используют консервативный ограничивающий прямоугольник и отмечают `safe_to_execute=False`; **не использовать их rectangle-model coverage как игровой PASS**. Их переход на native-footprint-validated алгоритм — отдельная разработка/эксперимент.
