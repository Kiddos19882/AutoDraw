# Документация AutoDraw

**Статус:** основной индекс документации  
**Продукт:** AutoDraw 1.8.3  
**Корень приложения:** `AutoDraw_Stage20/`

Этот каталог содержит актуальную структурную документацию и файлы управления проектом. Документы описывают состав репозитория, назначение компонентов, конфигурацию, пользовательские данные, локальную разработку, сборку, тестовые команды и порядок ведения работ.

Документация **не является аудитом поведения программы**. В ней не оцениваются алгоритмическая корректность, визуальное качество, производительность, точность измерений или безопасность runtime-операций. Если для описания интерфейса компонента используется его исходный код, фиксируется только его место и заявленная ответственность.

## Приоритет источников

1. Фактическое содержимое файлов в текущей ветке.
2. Конфигурационные файлы, манифесты и сценарии запуска.
3. Тестовые файлы — как каталог тестовых точек, не как доказательство поведения приложения.
4. Документация, связанная с соответствующей версией исходников.
5. Исторические отчёты и записи журнала.

При расхождении документации с текущей структурой репозитория исправляется документация, а не исходный код. Изменения кода в рамках документационной работы не допускаются.
