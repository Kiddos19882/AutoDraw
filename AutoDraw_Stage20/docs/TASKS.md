# Реестр задач AutoDraw

Реестр содержит задачи по документации и организации проекта. Статусы относятся к управлению работами, а не к оценке качества программы.

## Статусы

- `TODO` — не начато.
- `IN_PROGRESS` — выполняется.
- `BLOCKED` — ожидает решения или входных данных.
- `DONE` — выполнено и проверено.
- `ON_HOLD` — отложено.

## Правила обновления

- У каждой задачи должен быть уникальный ID.
- Задача получает `DONE` только после фактической проверки результата.
- Если задача изменяет исходный код, она не относится к текущей документационной инициативе.
- Не переносить в этот реестр аналитические выводы о поведении программы.
- При закрытии задачи добавить запись в WORK_LOG.
