Egret 5.4.1 — offline GraphicsNode reference

Страница загружает локальные Egret engine и game bundles, создаёт настоящий com.magnetjoy.pet.ui.board.BoardPane, вызывает его redraw() и напрямую растеризует его GraphicsNode через Egret CanvasRenderer, а отдельный probe запускает настоящий Egret WebGLRenderer с offscreen WebGL buffer для всех 18 fixture/width combinations. Это не live game session: pointer input не отправляется и CHALK не расходуется.

PNG source texture строится из GraphicsNode реального BoardPane, включая прозрачный прямоугольник resetBg() и board scrollRect; manual path transcription проверяется попиксельным сравнением с настоящим BoardPane. PNG masked board дополнительно композитит результат через Canvas2D как контрольный composite. Отдельный WebGL probe использует настоящий Egret WebGLRenderer с BoardPane mask и scrollRect для каждого fixture; все 18 WebGL PNG и параметры texture сохраняются отдельно. Canvas2D composite сравнивается с WebGL output по пикселям. Это offscreen engine test, не доказательство pixel equivalence с live game capture.

Парный offline replay принятых точек игры

Вставь полный monitor_report.json последнего Game Monitor run. Replay принимает ровно один strokeId и только принятые игрой board-local координаты; при pointDelta > 1, отсутствующих acceptedPoint или отсутствии неизменного renderer_geometry_at_start/end он откажет. Параметры Stage, canvas backing, CSS transform, screen/viewport, DPR и scale автоматически берутся из этого же run — старый snapshot 2026-11-04 не используется. Массив координат и события без renderer geometry не подходят для paired replay.

Для точного сопоставления выбери фактический режим и line width из того же run. Полученные PNG и manifest относятся к тем же принятым точкам, но не воспроизводят DOM timing или фазу ENTER_FRAME.
