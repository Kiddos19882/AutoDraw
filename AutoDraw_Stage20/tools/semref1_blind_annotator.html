AutoDraw / SEMREF1 — разметка для независимой проверки

Здесь отображается только исходный файл AutoDraw. Цветные штрихи — исключительно твои собственные отметки, не предложения нейросетей или алгоритма. Работает локально в браузере, без загрузки изображений на сервер.

Для строгой проверки каждому из четырёх оригиналов нужны две независимые разметки от разных людей. Два разных псевдонима одного человека не считаются независимой проверкой. Просто просмотренные изображения не являются разметкой.

1. Загрузить подлинный оригинал

Выбери соответствующий оригинал из ранее полученного GitHub-архива. Проверяются его SHA-256 и размер после декодирования; другое изображение не будет принято.

2. Разметить только то, что можешь уверенно определить

Отмечай небольшие, но очевидные участки. Не надо закрашивать картинку полностью. Необозначенные области остаются НЕПРОВЕРЕННЫМИ и не попадут в оценку безопасности.

Оригинал ещё не загружен.

3. Сохранить разметку (2 файла на одно изображение)

Сохранить PNG меток Сохранить JSON проверки

Сохрани оба файла. PNG содержит строго 5 заданных цветов без сглаживания, в исходных размерах. JSON содержит SHA-256 и подтверждение автора. Время и идентификатор автора нельзя считать независимым доказательством личности.

Ожидание подлинного оригинала.

Пояснение по научному статусу

Это только средство сбора разметки. Оно не проверяет независимость людей, не определяет игровые владельцы 128 цветов, не рассчитывает native footprint кисти и не разрешает штрихи. Пока не получены оба независимых комплекта по каждому из 4 DEV, SEMREF1 и строгий S4 остаются BLOCKED. H8, BLIND120 и другие резервные данные не открываются.
